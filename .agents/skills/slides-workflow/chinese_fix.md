# chinese_fix.py — Markdown 源码排版修复工具

## 功能说明

`chinese_fix.py` 依据 `markdown-sop.md` 规则,对 Markdown 源码行进行批量排版修复。

### 规则零 · Markdown 结构冻结

所有规则生效前,先把这些结构整段替换为占位符,处理完毕再还原:

- 围栏代码块 ```` ```...``` ````(跨行)
- 行内代码 `` `...` ``
- Markdown 图片 `![alt](url)`
- Markdown 链接 `[text](url)`
- 裸 URL `https://...`

占位符采用 `\x00F<idx>\x00` 与 `\x00I<idx>\x00` 双前缀:围栏用 `F`、行内用 `I`,避免外层与逐行处理互相吞噬。

**副作用**:链接与图片内的 text 不参与排版。如需对链接文字精细排版,请手动处理。

### 规则一 · 全角标点 → ASCII

| 替换前 | 替换后 |
|--------|--------|
| `，` | `,` |
| `、` | `,` |
| `；` | `,` |
| `：` | `:` |
| `？` | `?` |
| `！` | `!` |
| `——` | `-` |
| `…` | `...` |
| `（` `）` | `(` `)` |

### 规则二 · 括号间距

**内侧含 ASCII 字母**(如英文术语):

```
Sponsor(Sponsor)       →  Sponsor (Sponsor)
A(B)C                  →  A (B) C
项目管理（PMBOK）方法   →  项目管理 (PMBOK) 方法
```

**纯 CJK 内容**:

```
这是（中国）的  →  这是 (中国) 的
```

- 左括号前、右括号后各加空格(邻位非空白时生效;行首/行尾的括号也补空格)
- 括号内部统一去空格

### 规则三 · ASCII 双引号间距

```
说"你好"                  →  说 "你好"
这是"中"间                →  这是 "中" 间
这是"test" and "中文"间   →  这是 "test" and "中文" 间
```

- 开引号前加空格(前邻非空白时)
- 闭引号后加空格(后邻非空白时)
- 引号内侧空格统一去除

### 规则四 · 列表项行尾清理

```
- 项目定义。  →  - 项目定义
- 项目定义,   →  - 项目定义
- 项目定义.   →  - 项目定义
- 项目定义：  →  - 项目定义
- 项目定义？  →  - 项目定义?   ← 问号保留
```

- 去除末尾中文标点(,。、;:!…—)与 ASCII 标点 `,` `.` `:`
- 英文问号 `?` 保留(题目本身);中文 `？` 经规则一变 ASCII `?` 后自然保留

### 规则五 · 英文标点后跟 CJK 时加空格

```
项目.定义   →  项目. 定义
项目,定义   →  项目, 定义
项目:定义   →  项目: 定义
是吗?请思考 →  是吗? 请思考
```

- `.` `,` `:` `?` **只在后邻 CJK 时**插入空格
- 数字、文件名、URL、代码内容天然豁免(`1.5` / `1,000` / `file.py` / `12:30` 不变)

### 规则六 · CJK ↔ 字母/数字/% 间距

```
这是abc文字     →  这是 abc 文字
中文123数字     →  中文 123 数字
使用率80%很高   →  使用率 80% 很高
```

- CJK 与 ASCII 字母/数字/`%` 相邻时两侧加空格
- 含 placeholder 边界:若 CJK 紧邻代码/链接/URL 占位符,也补空格(还原后自然体现)

### 规则七 · 运算符间距

```
速度>100时  →  速度 > 100 时
阈值=5时    →  阈值 = 5 时
```

- 运算符集:`= < > + &`
- 只在 CJK 参与时两侧加空格(`a=b` 纯 ASCII 不动)
- **排除** `|`(表格)、`*`(强调/列表)、`-`(列表/破折号)、`/`(路径)、`#`(标题) — 避开 Markdown 语法字符

### 规则八 · 斜杠间距

```
中国/日本  →  中国 / 日本
```

- 只处理 `CJK/CJK` 场景
- URL 已由规则零冻结,纯 ASCII 路径不触发

## 使用方式

```bash
# 对单个文件(原地修改)
python3 chinese_fix.py /Users/Freeman/Documents/products/courses/library/texts/pmi-slide-drafts/slide-drafts/pmi-1-1.md

# 无参数:stdin → stdout
cat /Users/Freeman/Documents/products/courses/library/texts/pmi-slide-drafts/slide-drafts/pmi-1-1.md | python3 chinese_fix.py

# 用 - 指定 stdin
python3 chinese_fix.py - < /Users/Freeman/Documents/products/courses/library/texts/pmi-slide-drafts/slide-drafts/pmi-1-1.md
```
