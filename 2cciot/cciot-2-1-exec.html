将虚拟机运行结构中的对象与其作用匹配

正确答案：宿主机 → 提供物理 CPU、内存、磁盘和网络等资源；虚拟化层 → 抽象并分配物理资源，承载虚拟机；虚拟机 → 由虚拟硬件组成的逻辑计算机；客户操作系统 → 在虚拟机内部运行并使用虚拟硬件

物理资源来自宿主机，虚拟化层负责抽象和分配，虚拟机提供逻辑硬件环境，客户操作系统运行在这个环境中

正确答案：让同一局域网的同学直接访问虚拟机中的 Web 服务 → 桥接；让虚拟机访问互联网但不占用局域网独立地址 → NAT；分析不可信文件并只与宿主机交换结果 → 仅主机

第 6 题 / 共 10 题 · 多选题

虚拟机能够访问网站，但宿主机无法通过 SSH 登录。排查时应该检查哪些方面？

正确答案：连接的 IP 是否属于当前虚拟机、宿主机到虚拟机的网络路径是否可达、虚拟机中的 SSH 服务是否运行、防火墙是否允许 SSH 端口、用户名、密钥或密码是否正确

能够访问网站只证明虚拟机向外的一条路径成立；SSH 还依赖正确地址、反向可达路径、服务、端口和认证
