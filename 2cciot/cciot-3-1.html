### 公有云 - 由云服务提供商建设 - 对公众开放 - 云服务平台
### 公有云的特点 - 基础设施所有权属于云服务提供商 - 成本较低 - 易于使用, 易于扩展 - 资源共享 - 高安全性
![Public Cloud](img/c03/1_Private-Cloud-Public-Cloud.png) #### Public Cloud
### 主流公有云提供商 - Amazon AWS - Microsoft Azure - Google Cloud - 阿里云 - 腾讯云 - 华为云
### Amazon AWS - 2006 年推出 - 全球最大的云服务提供商 - 全球第一, 约 30% 左右市场 - 服务最丰富、生态完善 - 价格较高、学习曲线陡峭
![Amazon AWS](img/c03/2-aws.jpg) #### Amazon AWS
### Microsoft Azure - 2010 年发布 - 数据中心数量全球领先 - 全球第二, 约 20% 左右市场 - 与微软产品高度集成 - 部分服务成熟度较低 - 在企业数字化转型和混合云方案上优势明显
![Microsoft Azure](img/c03/3-Azure.jpg) #### Microsoft Azure
### Google Cloud - 2011 年发布 - 数据中心分布在全球主要区域 - 排名第三, 约 10% 左右市场 - 大数据、AI、机器学习方面表现突出 - 企业客户资源相对较弱 - 在开发者群体和创新型企业中颇受欢迎
![Google Cloud](img/c03/4-google-cloud.png) #### Google Cloud
### 阿里云 - 2009 年推出 - 在中国和亚洲市场占据领先地位, 全球前五 - 数据中心遍布全球 - 本地化服务强大 - 电商行业渗透率高 - 在欧美市场影响力有限 - 是双 11 的核心技术支撑
![Ali Cloud](img/c03/5-aliyun.jpg) #### 阿里云
### 腾讯云 - 2010 年推出 - 在中国市场稳居前列 - 中国市场第二, 全球排名靠前 - 在游戏、视频、社交领域具备强大技术积累 - 安全和音视频服务突出
![Tencent Cloud](img/c03/6-Tencent_Cloud.jpg) #### 腾讯云
### 华为云 - 2017 年全面进入公有云市场 - 成长速度快 - 中国三大云厂商之一 - 硬件与网络优势明显 - 在政企市场和电信行业具备强大优势
![Huawei Cloud](img/c03/7-huawei-cloud.png) #### 华为云
### 公有云专业名词 - 区域 - 可用云 - 弹性云服务器 - 虚拟私有云 - 安全组
### 区域 - 云服务商在全球划分的地理区域 - 每个区域包含一个或多个数据中心 - 帮助用户选择接近业务或客户的节点 - 降低延迟, 满足合规要求 - 支持数据主权和合规性 - 提供冗余和容灾能力 - 跨区域通信成本较高 - 常用来设计高可用架构和跨区域备份
![Regions](img/c03/8-regions.png) #### Regions
### 可用区 - 区域内部的独立数据中心单元 - 具备独立供电、网络和冷却 - AWS 首创的架构理念 - 提供同一区域内的高可用部署, 避免单点故障 - 同一可用区内低延迟, 跨可用区容灾能力强 - 不同可用区间可能存在额外网络费用
![Virtual Private Cloud](img/c03/9-vpc.png) #### Virtual Private Cloud
### 弹性云服务器 - 基于虚拟化技术的可弹性伸缩计算资源 - 云计算的基础服务之一 - 最早由 AWS EC2 提出 - 用户可按需创建、释放、扩展或缩减计算资源 - 计费灵活, 支持快速扩展, 应用场景广泛 - 支持多种操作系统镜像和应用模板
### 虚拟私有云 - 用户在公有云中划分的逻辑隔离网络空间 - 随着企业上云对网络隔离和安全要求提高而普及 - 提供子网、路由、网关、安全策略等自定义能力 - 隔离性强, 网络拓扑可控, 类似本地数据中心 - 配置复杂度较高 - 常与 VPN 或专线连接结合, 实现混合云架构
### 安全组 - 云服务器的虚拟防火墙 - 控制入站与出站流量 - 起源于 AWS EC2 的安全管理机制 - 基于规则设置流量, 按实例或子网生效 - 操作灵活, 支持精细化访问控制, 易于管理 - 配置错误可能引发安全风险 - 通常与网络 ACL、防火墙、入侵检测等配合使用
![Security Group](img/c03/10-security-group.png) #### Security Group
