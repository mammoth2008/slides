VIRTUAL MACHINE LAYERS
CCIOT | CH02 | 2.1 | 虚拟机如何运行

Type 1 与 Type 2 的区别

虚拟化层位的不同，决定了类型不同

Type 1：裸机型

物理硬件之上直接运行虚拟化层，再由虚拟化层承载多个虚拟机

主要用于服务器集中承载与管理

Type 2：宿主型

物理硬件上运行宿主操作系统，虚拟化软件是运行在宿主操作系统上的应用程序

VMware Workstation 是典型例子

Takeaway

以上只是简单分类，具体产品的内部架构往往更加复杂

CLASSROOM ENVIRONMENTS
CCIOT | CH02 | 2.1 | 虚拟网络

三种网络模式

根据互联网、宿主机和局域网访问需求判断合理的模式

桥接

虚拟机被视为一台单独计算机，可以被同一网络中的其他设备直接访问

NAT

虚拟机通过宿主机转换地址访问外部网络，依赖宿主机的网络访问能力

仅主机

虚拟机只连接宿主机私有网络，默认不能访问互联网

Takeaway

网络模式安排的是通信路径，服务、端口或防火墙需要自行设置

重点是虚拟机和宿主机的关系

NAT AND SSH
CCIOT | CH02 | 2.1 | 虚拟机演示

虚拟机能上网，为什么 SSH 失败？

  1. 01检查地址：连接的 IP 是否属于当前虚拟机
  2. 02检查路径：宿主机能否到达虚拟机所在网络
  3. 03检查服务：虚拟机中的 SSH 服务是否正在运行
  4. 04检查端口：防火墙是否允许对应端口
  5. 05检查认证：用户名、密钥或密码是否正确
Takeaway

能够访问网站，只能证明单向路径成立

排查顺序就是错误的常见程度

本节回顾

判断虚拟化方案时，沿着资源、网络、状态和使用目标逐层分析

  1. 01资源抽象：虚拟化层把物理资源呈现为虚拟硬件

  4. 04网络路径：桥接、NAT 和仅主机安排不同的可达范围
  5. 05状态管理：快照用于回退，克隆用于复制，备份用于恢复
  6. 06环境选择：Workstation 展示完整虚拟机机制，WSL2 支持日常使用
