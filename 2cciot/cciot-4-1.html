### 私有云 - 为特定少量用户建立的云服务 - 由用户自行管理和维护 - 所需成本远大于公有云
![Private Cloud](./img/c04/0-Private-Cloud-Services-Market.png) #### Private Cloud Services Market
### 私有云的优势 - 数据更安全 - 网络更稳定 - 可以实现定制化
### 常用私有云软件系统 - OpenStack - CloudStack - oVirt - VMware vSphere / vCloud Suite - Microsoft Azure Stack - 华为 FusionCloud / FusionSphere
### OpenStack - 2010 年由 NASA 和 Rackspace 发起 - 模块化设计 - 涵盖计算、存储、网络等核心功能 - 社区活跃, 支持大规模部署, 生态丰富 - 部署和运维复杂, 学习成本高 - 典型应用：科研机构、大型互联网公司
![OpenStack](./img/c04/1-openstack.png) #### OpenStack
### CloudStack - 起源于 Cloud.com - 后由 Apache 基金会托管 - 提供计算、存储、网络等一体化功能 - 部署相对简单 - 适合中小规模私有云环境 - 生态偏小 - 典型应用：中小企业, 成本敏感型用户
![CloudStack](./img/c04/2-Apache-CloudStack.jpg) #### CloudStack
### oVirt - 基于 KVM 的开源虚拟化管理平台 - 更专注于虚拟化集群的管理和调度 - 与 Red Hat Enterprise Linux 生态紧密结合 - KVM 底层性能好, 虚拟化功能强 - 功能偏向虚拟化, 不够完整 - 典型应用：企业数据中心, 虚拟化优先的场合
### VMware vSphere / vCloud Suite - VMware 企业级私有云解决方案 - 基于成熟的虚拟化技术 vSphere - 提供云化管理套件 - 性能稳定、功能成熟、企业支持完善 - 成本高, 依赖 VMware 生态 - 典型应用：金融、电信、政企 IT 环境
![VMware vSphere](./img/c04/3-vcloud-vmware.png) #### VMware vSphere
### Microsoft Azure Stack - 微软推出的混合云平台 - 与 Azure 公有云高度兼容 - 部署在本地数据中心 - 与微软产品生态深度集成, 支持混合云场景 - 硬件要求高 - 典型应用：有微软生态, 需混合云架构
![Microsoft Azure Stack](./img/c04/4-microsoft-private-clouds-final.png) #### Microsoft Azure Stack
### 华为 FusionCloud / FusionSphere - 面向企业和政企市场的私有云解决方案 - 基于华为硬件与 ICT 设备 - 支持虚拟化、云平台、混合云 - 软硬件一体化, 网络与 5G 技术结合紧密 - 海外市场生态较弱 - 典型应用：政府、国企、电信运营商
