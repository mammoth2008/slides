第 1 题 / 共 6 题 · 匹配题

将大数据 5V 与对应的处理挑战匹配

正确答案：体量 Volume → 数据规模持续增长带来的存储与计算压力；速度 Velocity → 数据快速产生并要求及时处理；多样性 Variety → 数值、文本、图像和日志等格式并存；真实性 Veracity → 数据缺失、噪声、偏差和来源可信度问题；价值 Value → 数据能否支持明确目标和可行动判断

5V 描述不同处理挑战，不能只用数据量大来概括大数据问题

第 2 题 / 共 6 题 · 排序题

按一条可追溯的数据智能主路径排列步骤

  1. 清洗、校准、去重并处理缺失异常
  2. 将结果交给受控决策并持续监控反馈
  3. 组织和存储数据
  4. 采集数据并记录来源与时间
  5. 明确业务目标、对象和数据语境
  6. 分析或训练模型并在未见数据上评估

正确答案：明确业务目标、对象和数据语境 → 采集数据并记录来源与时间 → 清洗、校准、去重并处理缺失异常 → 组织和存储数据 → 分析或训练模型并在未见数据上评估 → 将结果交给受控决策并持续监控反馈

数据智能从目标和语境开始，经过质量治理、分析评估后才能进入行动，反馈又用于监控和改进

第 3 题 / 共 6 题 · 匹配题

将数据形状与更合适的存储思路匹配

正确答案：订单、用户和支付之间有稳定关系并需事务一致性 → 关系数据库；设备状态按设备 ID 高频读取且结构简单 → 键值数据库；设备上报字段随型号变化并保留嵌套结构 → 文档数据库；路网节点和边之间需要路径查询 → 图数据库

存储选择取决于数据形状、查询方式、一致性和扩展需求，不存在适合所有任务的单一数据库

怎样让道路结冰预测安全地影响养护行动？

对照答案：记录传感器、天气、位置和时间语境，治理缺失与异常；用独立数据验证模型并报告阈值、误报漏报和适用范围；输出应带模型与数据版本，由养护人员结合现场证据复核，再按风险级别采取预警、巡检或处置；运行中监控分布变化和反馈，保留权限、日志、隐私、降级与回滚责任
