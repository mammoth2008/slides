# 完成间隔等于专注学习时间吗？

本轮备课生成的参考笔记，供课堂核对；不是学生已经完成的作业。

## 来源与原文概述

[原文短摘录](../sources/section-2-2.md)，§2.2，原 PDF 物理页 6。平台领取作业到提交答案的间隔，平均 58 分钟；不能准确反映每次实际用时，但可作平均周末作业用时的合理代理。

## 我的解释

起止时间不能证明中间一直在学习。因此我保留“平均作业完成间隔 58 分钟”，不把它改成“平均专注学习 58 分钟”。
