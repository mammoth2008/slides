# DeepSeek Harness：课堂证据定位卡

2026-10-18。本卡是授课前待执行的定位步骤，不是实际界面截图或成功运行记录。本机常见应用目录未找到 DeepSeek Harness，当前界面与候选插件仍待教学设备验证。课堂继续使用 DeepSeek Harness。

## 教师先做一次，学生再指认同一位置

使用无答案包的 reading-project 和 start-task.md，只处理其中公开摘录。记录本次应用版本、操作系统、模型和接口；不要记录密钥。

| 实际动作 | 需要展示给学生的证据 | 本次位置或状态 |
| --- | --- | --- |
| 选择解压目录，建立新任务 | 当前目录与输入区；请求点名的三个文件 | 待实际定位 |
| 发起一次来源读取 | 请求中的文件路径、执行工具标识、实际返回内容 | 待实际定位 |
| 保存并回读新文件 | 输出位置；文件中一条修订与其来源 | 待实际定位 |
| 在单独演练任务中暂停 | 暂停操作入口；后续新动作、在途请求与已写文件的状态 | 待实际定位 |

教师先展示一项，学生再指认自己的对应位置。记录当前版本的真实界面名称；不要按其他宿主的截图寻找同名按钮。第一条返回后先让学生写“下一步做什么、依据哪条返回”，再继续。

若没有可见的工具返回，可查看该版本提供的导出记录或运行详情；仍无法观察时，此项记未验证。若没有自动额度设置，由人按任务约定计数并暂停，不能记成系统强制限额。暂停不等于撤回已写内容或保证已发请求取消。

## 新增插件开课条件

先完成 [候选核对表](plugin-check.md)，向学生提供一个真实安装对象及其版本、工具标识、安装与停用路径。需在本次宿主中完成教学 CSV 的真实调用、结果核对与停用后检查。

这些条件未满足时，教师可以组织 CSV 独立复算和构造记录诊断；这两项不替代新增插件实际操作。明确标记待补做的安装、调用与停用，不要求学生猜一个包名自行安装。

## 两课最低完成物

第一课：修订文件＋一段真实返回及下一步理由。第二课：扩展验证记录＋暂停/接管记录。可接写在同一份运行记录，不重复交表。没有完成的动作如实标记，修复环境后补做。
