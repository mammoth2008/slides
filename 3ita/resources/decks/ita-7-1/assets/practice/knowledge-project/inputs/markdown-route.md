# 用实际编辑器完成 Markdown 路径

Markdown 是文件格式。本次比较应记录实际编辑器、版本、插件、PDF 阅读器和引用办法；不把文件格式本身视为一个具备所有功能的应用。

## 基础路径

使用能打开并保存 UTF-8 纯文本的编辑器，保留 .md 文件名及原目录。可用已经熟悉的编辑器，无需为这次比较额外安装插件。

1. 打开 notes/index.md，选择一个问题。若编辑器支持链接跳转，沿链接打开卡片；若不支持，按相对路径在文件管理器中打开目标文件。这是单元 3 已练过的路径判断。
2. 打开已取得的正确版本 PDF，用其阅读器定位章节及页码，对照卡片的一句话。把原文位置、自己的改句或保留理由写回卡片。
3. 跨文献比较前，取得 real-comparison-reading.md 指向的第二份真实研究。使用同一比较字段，实际回查一处条件差异。只读题录或摘要时，不记录全文比较完成。
4. 在笔记中形成一条包含作者、年份、题名和标识符的引用文本。基础路径可手工填写和修订；更改一处题录年份后，实际查找需要更新的引用，记录修改处数。若使用自动引用工具，记录名称与实际联动结果。

## 同任务比较时

两种安排使用相同材料、问题与完成标准；按教师分配交换先后顺序，记录熟悉程度、准备时间、操作和核验时间。把找回原文、回查主张、跨文献比较、引用修订分别记为完成、部分完成或未测试。

无法点击链接不一定等于无法找回来源；手工完成也不等于自动维护。记录真实做法和代价，结论只解释本人的工具安排。各编辑器的具体菜单以实际版本为准，本材料不声称已在学生设备验证。
