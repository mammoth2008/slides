第 3 题 / 共 12 题 · 匹配题

将可靠性机制与主要职责匹配

正确答案：日志 → 保存更新及提交信息，支持所选恢复算法；检查点 → 保存可恢复状态，减少启动恢复工作；非易失介质 → 保留字节仍需一致更新与持久化协议；复制 → 保存其他节点副本，按提交与故障模型提供接管能力

持久性恢复和高可用相关但不相同，复制不能替代历史恢复，NVM 也不自动提供事务一致性

第 4 题 / 共 12 题 · 匹配题

将硬件并行概念与优化对象匹配

正确答案：SIMD → 一条指令并行处理多个数据元素；多线程 → 多个任务或数据分区由不同线程并行执行；NUMA 局部性 → 尽量让线程访问本地内存，减少远程节点访存

数据级并行、任务级并行和访存位置是不同优化维度

数据库算子交给 GPU 可能获得收益通常需要哪些条件？

正确答案：数据规模足以摊薄传输与启动开销、算法具有大量规则、可并行计算、CPU 与 GPU 之间的数据移动可控、分支和随机访问不过度破坏并行效率

GPU 是特定算子加速器，数据移动和控制流可能抵消计算收益

第 6 题 / 共 12 题 · 匹配题

按本节接口层次，将介质与角色匹配

正确答案：DRAM 主存 → 易失的内存读写工作区；某类持久内存 → 内存接口访问，仍需持久化顺序和一致性协议；SSD／磁盘 → 块 I/O 持久设备，可放数据、日志或备份

NVM 是技术统称，闪存也属于非易失性技术；这里比较访问接口与角色，不把 NVM 和 SSD 一概做成互斥类别

内存订单数据库断电后，为什么“有复制”仍不等于订单一定可恢复？

对照答案：还要确认副本是否同步到已提交状态、故障是否同时影响副本、复制协议能否区分已提交和未提交更新，以及副本本身是否一致可用。日志和检查点提供事务恢复证据，NVM 可保存本地持久状态，复制提高节点可用性；它们需要共同满足提交和恢复合同
