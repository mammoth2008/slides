将数据库类型与典型优化假设匹配

正确答案：磁盘驻留数据库 DRDB → 数据主要驻留外存，缓冲区和减少磁盘 I/O 是核心路径；内存数据库 IMDB → 主要工作数据驻留内存，布局、Cache、并行和持久化补偿需重新设计

两类系统都会使用 CPU、内存和外存，区别在主存储假设和围绕该假设形成的结构

第 3 题 / 共 7 题 · 匹配题

将可靠性机制与主要职责匹配

正确答案：日志 → 保存事务更新证据以支持 UNDO／REDO；检查点 → 周期性保存可恢复状态并缩短重做范围；NVM 持久内存 → 让部分数据或日志在断电后保留，但仍需一致更新协议；复制 → 在另一节点保存副本以提高可用性和故障切换能力

持久性恢复和高可用相关但不相同，复制不能替代历史恢复，NVM 也不自动提供事务一致性

第 4 题 / 共 7 题 · 匹配题

将硬件并行概念与优化对象匹配

正确答案：SIMD → 一条指令并行处理多个数据元素；多线程 → 多个任务或数据分区由不同线程并行执行；NUMA 局部性 → 尽量让线程访问本地内存，减少远程节点访存

数据级并行、任务级并行和访存位置是不同优化维度

第 5 题 / 共 7 题 · 多选题

数据库算子交给 GPU 可能获得收益通常需要哪些条件？

正确答案：数据规模足以摊薄传输与启动开销、算法具有大量规则、可并行计算、CPU 与 GPU 之间的数据移动可控、分支和随机访问不过度破坏并行效率

GPU 是特定算子加速器，数据移动和控制流可能抵消计算收益

第 6 题 / 共 7 题 · 匹配题

将介质与典型数据库角色匹配

正确答案：DRAM → 提供低延迟易失主存和热数据工作区；NVM → 在较低延迟下提供持久数据或日志层，但写入和一致性特征不同于 DRAM；SSD／磁盘 → 提供大容量持久存储、后备副本或冷数据层

实际系统可以分层组合介质，选择依据是延迟、带宽、持久性、容量、耐久和成本

第 7 题 / 共 7 题 · 回想题

内存订单数据库断电后，为什么“有复制”仍不等于订单一定可恢复？

对照答案：还要确认副本是否同步到已提交状态、故障是否同时影响副本、复制协议能否区分已提交和未提交更新，以及副本本身是否一致可用。日志和检查点提供事务恢复证据，NVM 可保存本地持久状态，复制提高节点可用性；它们需要共同满足提交和恢复合同
