ROLE CHANGES
DBPA | CH04 | 4.1 | 4.2

自主存取控制 DAC：授权者决定访问权限

对象所有者或持有转授权资格的人，可以允许别人对指定对象执行某种操作

授权者

DBA、对象属主，或拥有该权限及 WITH GRANT OPTION 的用户可以作出授权决定

授权内容

指定用户、数据库对象和允许的操作

泄露风险

权限可能沿转授权继续传播，也可能授给了不该获得的人

Takeaway

DAC 检查操作权限，完整性检查数据规则

12/19
DAC
DBPA | CH04 | 4.1 | 4.2

强制存取控制 MAC：按密级限制读写

采用 MAC 的系统按主体许可证与客体密级判定读写权限

概念含义本例
主体发起访问的用户或进程持有 S 级许可证的用户
客体被访问的表、视图或文件标为 C 级的成绩表
密级标记主体许可证与客体密级S 与 C 的高低关系决定读写限制
普通授权通过→密级规则通过→允许访问
Takeaway

访问须同时通过 DAC 与 MAC；普通 GRANT 不改变系统的密级规则

MAC LABELS
DBPA | CH04 | 4.1 | 4.2

MAC 防止高密级信息写入低密级对象

设密级顺序为 TS >= S >= C >= P

规则条件结果
读取主体许可证级别 ≥ 客体密级才允许读取
写入主体许可证级别 ≤ 客体密级才允许写入
双重检查DAC 与 MAC 都通过才允许访问

SECURITY STANDARDS
DBPA | CH04 | 4.1

练习：判断四个访问请求

判断学生查整表、教师改成绩、回收 U5 后 U7 插入、S 写 C 的放行条件

请求一：学生查 Student

学生已登录；整表查询需 SELECT 权限，受限视图可限定为个人记录

请求二：教师改成绩

T17 修改成绩：有效角色可提供 UPDATE(Grade) 权限；完整性约束限定成绩的合法取值

请求三：U7 继续插入

级联回收 U5 会撤销沿该路径授予 U7 的 INSERT；U7 从其他独立路径获得的同一权限保留

请求四：S 写入 C

MAC 拒绝 S 向 C 写入，以阻止高密级信息向下流动；此时 DAC 的允许结果不足以放行
