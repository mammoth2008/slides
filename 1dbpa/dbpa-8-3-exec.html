将 JDBC 执行接口与适用场景匹配

正确答案：Statement → 执行没有外部参数且不重复的固定 SQL；PreparedStatement → 执行带输入参数、需要绑定并可能重复运行的 SQL；CallableStatement → 调用存储过程或存储函数接口

PreparedStatement 通过参数绑定分离 SQL 结构与数据，CallableStatement 面向数据库端存储程序

按 JDBC 访问数据库的主要步骤排列

  1. 读取 ResultSet、更新行数或输出参数
  2. 绑定输入参数并执行
  3. 创建 Statement、PreparedStatement 或 CallableStatement

第 3 题 / 共 7 题 · 匹配题

将 JDBC 方法与数据流方向匹配

正确答案：setXXX → 把 Java 值绑定到 SQL 参数占位符；executeQuery → 执行预期返回 ResultSet 的查询；next → 把 ResultSet 游标移动到下一行并报告是否存在；getXXX → 按 SQL／Java 类型映射读取当前行列值；registerOutParameter → 为存储程序声明应用要接收的输出参数

参数绑定是应用到数据库，结果读取是数据库到应用，两种方向都要处理类型与 NULL

第 5 题 / 共 7 题 · 匹配题

将 MVC／DAO 层与教师回复业务中的职责匹配

正确答案：Controller → 接收请求、校验路由并协调一次业务用例；Model／Service → 执行教师是否可回复、状态转换等业务规则；DAO／Repository → 封装 Feedback 数据的查询与持久化；JDBC／ORM → 把数据库调用、参数和结果映射为应用对象；View → 展示回复表单和处理结果

分层把界面、业务规则和数据访问解耦，避免 Controller 或 View 直接拼接数据库细节

使用连接池时仍需治理哪些边界？

正确答案：最大连接数和等待超时、借用后及时归还连接、连接失效检测与泄漏监控、事务、会话状态和隔离级别复位

连接池复用物理连接，但容量、状态、泄漏和故障仍需明确管理
