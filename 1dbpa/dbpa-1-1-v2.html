1.1.1 / DB DBMS DBS

四个基本概念

日常所说的数据库，可能指数据库、数据库软件或数据库系统

DATA
数据：描述事物的符号记录，是存储和处理对象
DB
数据库：按数据模型组织、长期存储、可共享的大量数据集合
DBMS
数据库管理系统：位于用户与操作系统之间，统一管理数据库的软件
DBS
数据库系统：由数据库、DBMS、应用系统、DBA 和用户共同构成

1.1.2 / DATA MANAGEMENT

数据管理三阶段

谁管理数据、数据能否共享、数据和程序是否独立？

MANUAL
人工管理阶段：应用程序自己管理数据，数据不长期保存、不共享、不独立
FILE
文件系统阶段：数据可以长期保存，但文件彼此孤立，共享弱、冗余高
DATABASE
数据库系统阶段：DBMS 面向组织整体，统一管理共享数据

1.1.2 / SYSTEM FEATURES

数据库系统特点

数据共享，意味着把结构、独立性和控制机制交给 DBMS

01 整体结构化 数据之间也有联系
02 共享、低冗余 减少重复保存和不一致
03 数据独立性 物理变化 / 逻辑变化尽量少影响应用
04 统一控制 安全性 / 完整性 / 并发 / 恢复
