SC 表以 Sno 和 Cno 共同唯一标识选课记录，主码应怎样定义？

正确答案：使用表级 PRIMARY KEY (Sno, Cno) 定义复合主码

一个表只有一个主码约束，复合主码要求两个属性组合唯一且每个分量非空

第 3 题 / 共 7 题 · 匹配题

将业务数据与选型时最重要的依据匹配

正确答案：学生姓名 → 最大长度、字符集和是否允许为空；出生日期 → 日期运算和合法日期范围；成绩 → 允许范围、精度及是否需要小数；订单金额 → 精确十进制位数和金额运算

第 4 题 / 共 7 题 · 单选题

删除一个仍被视图和外码依赖的表时，RESTRICT 与 CASCADE 的主要差异是什么？

正确答案：RESTRICT 在存在依赖时拒绝删除，CASCADE 可能连带处理依赖对象

DROP 改变数据库结构，执行前必须识别依赖范围；CASCADE 的具体连带行为还要按目标 DBMS 核查

为高频查询列创建索引前，哪些因素需要权衡？

正确答案：查询定位是否可能明显受益、列的选择性和常用查询条件、索引占用的存储空间、插入、删除和修改时的维护成本

索引提供候选存取路径，是否使用由优化器决定；它不能替代数据完整性约束

第 6 题 / 共 7 题 · 匹配题

将数据字典信息与 DBMS 的使用场景匹配

正确答案：表和列定义 → 解析并检查 SQL 中的对象与属性；主码、外码和检查约束 → 在数据更新时验证合法性；对象依赖 → 判断 ALTER 或 DROP 的影响范围；统计信息 → 为查询优化估计代价

要为 Course 表增加一个非空的学分列，而表中已有数据。写 ALTER 前需要检查什么，怎样降低结构变更风险？

对照答案：先明确学分的数据类型、合法范围和默认或回填规则；检查现有元组能否满足非空约束、相关视图和程序是否依赖原结构，以及目标 DBMS 的 ALTER 语法和锁定行为。可先设计可验证的回填步骤，再增加或收紧约束，并在变更前备份和核对影响范围
