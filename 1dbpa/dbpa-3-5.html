NULL 是什么？

Grade 是 NULL，就等于学生考了 0 分吧？

NULL 表示当前没有确定且可用的值；具体原因可能是未知、不适用或不便提供

语境含义例子
未知应该有值但目前不知道漏填出生日期
不适用当前对象或状态不需要这个值缺考没有成绩
不便提供值可能存在，但当前不宜填写不愿公开的联系方式
Takeaway

0、''、“NULL” 都是确定的值；NULL 表示当前没有确定且可用的值

NULL 是怎么产生的？

插入、更新和外连接都可能产生 NULL

插入

省略可空列或显式写入 NULL；SC.Grade 未列出 → NULL

更新

UPDATE ... SET Smajor = NULL，元组仍存在而属性被置空

外连接

未匹配时另一侧列只在查询结果中补为 NULL，不写回基本表

Takeaway

空值不是删除记录的替代方式

Grade = NULL 看起来最直接，为什么查不到缺考记录？

等号比较不能把 NULL 当成普通常量

SQL

02

Grade IS NOT NULL找到已有成绩的记录正确判断

主码不能空，可空外码可以暂缺

对 UNIQUE 中多个 NULL 的处理，使用前要核对目标 DBMS

约束NULL 规则课堂判断
NOT NULL禁止该列为空必须提供值或默认值
主码（Student.Sno）不能为空且必须唯一不能用 NULL 标识主体
复合主码（SC.(Sno, Cno)）组合唯一且两个组成列都不能为 NULLSno、Cno 单列可以重复
UNIQUE（扩展示例）标准约束；多个 NULL 的行为查目标 DBMS当前 Student/SC 基础 DDL 未定义
可空外码（Course.Cpno）NULL 不要求匹配父表；非 NULL 必须有效空外码不等于无效外码

NULL 参与比较会产生 UNKNOWN

含 NULL 的值无法与另一个值确定大小或相等关系

  • ■算术：NULL + 1 得到 NULL
  • ■普通比较：NULL = NULL 得到 UNKNOWN，不是 TRUE 或 FALSE
  • ■查询筛选：WHERE、HAVING 只保留条件结果为 TRUE 的行或组

UNKNOWN
DBPA | CH03 | 3.5 | 3.5.4

三值逻辑：由典型组合推导 UNKNOWN

NOT UNKNOWN 以后，怎么还是 UNKNOWN？

三值逻辑（Three-valued logic）同时处理 TRUE、FALSE 与 UNKNOWN

表达式结果
TRUE AND UNKNOWNUNKNOWN
FALSE AND UNKNOWNFALSE
TRUE OR UNKNOWNTRUE
FALSE OR UNKNOWNUNKNOWN
NOT UNKNOWNUNKNOWN
Takeaway

二值逻辑中，NOT 在真、假之间反转；三值逻辑中，NOT UNKNOWN 仍是 UNKNOWN

WHERE 只保留条件为 TRUE 的元组

成绩为空的记录不会被 < 60 自动当作不及格

02
03-- 只找该课程已知不及格的记录
SELECT Sno FROM SC
WHERE Cno = '81001' AND Grade < 60;
SQL
01
02
03-- 同时纳入该课程成绩为空的记录
SELECT Sno FROM SC
WHERE Cno = '81001' AND (Grade < 60 OR Grade IS NULL);
Takeaway

第二条用 OR Grade IS NULL 同时纳入成绩为空的记录

聚集函数对空值的处理

统计元组与统计非空列值不是同一个问题

写法统计对象空值影响
COUNT(*)元组数量不因某列为空而减少
COUNT(Grade)非空成绩数量跳过 Grade 为 NULL 的行
AVG(Grade)非空成绩平均值不把空值当成零分
  • 部分为空：成绩为 80、NULL、60 → COUNT(*) = 3，COUNT(Grade) = 2，AVG(Grade) = 70
  • 全部为空：COUNT(Grade) = 0，AVG(Grade) = NULL；HAVING AVG(Grade) >= 60 得到 UNKNOWN，该组不保留
