布隆过滤器的排除与误报

Bloom Filter：8 位全 0，h1=x mod 8，h2=(3x+1) mod 8

操作访问的位置判断
加入键 1、31 和 4；3 和 2置位集合{1,2,3,4}
查询 22 和 7，位置 7 为 0可排除
查询 91 和 4，两位都是 1假阳性：命中但没有 9
查询 33 和 2，两位都是 1再读真实数据确认
Takeaway

无假阴性要求过滤器完整、同步且未损坏；新增 2 后须同步置位。候选记录仍需核验合法性与提交状态

审计收据丢失后的去重重发

方案 A 的外部日志按事件 ID 去重，并检查相同 ID 对应相同内容

  1. 01投递器读取 PENDING 的 E01，发送固定内容与摘要
  2. 02外部日志追加 E01，返回收据；本次收据在网络中丢失
  3. 03投递器再次发送 E01，日志核对内容后返回原收据
  4. 04本地记录 ACKED；定期比对提交、投递与收录进度
Takeaway

同 ID 换内容报冲突，保留原记录；失败队列、积压告警和恢复演练用于发现未送达事件
