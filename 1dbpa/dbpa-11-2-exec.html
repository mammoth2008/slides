将转储方式与主要特点匹配

正确答案：静态转储 → 等待事务结束并暂停运行事务，副本一致但影响业务；动态转储 → 转储期间允许更新，需要日志协调副本时点；海量转储 → 复制完整数据库；增量转储 → 本节指只复制自上一次转储后变化的数据

静态／动态描述转储期间能否更新，海量／增量描述复制范围，是两条独立分类轴

第 4 题 / 共 11 题 · 排序题

使用检查点缩小系统故障恢复范围时按步骤排列

  1. 按恢复算法撤销未提交并重做需保证持久的事务
  2. 构造 UNDO-LIST 与 REDO-LIST
  3. 从检查点信息恢复当时的活动事务集合
  4. 向后扫描日志更新事务的提交或未完成状态
  5. 找到重新开始文件记录的最后有效检查点

正确答案：找到重新开始文件记录的最后有效检查点 → 从检查点信息恢复当时的活动事务集合 → 向后扫描日志更新事务的提交或未完成状态 → 构造 UNDO-LIST 与 REDO-LIST → 按恢复算法撤销未提交并重做需保证持久的事务

最后有效检查点提供分类起点；对跨越检查点的未完成事务，UNDO 仍可能回溯更早日志

第 5 题 / 共 11 题 · 匹配题

将恢复证据与主要作用匹配

正确答案：后备副本 → 提供某个转储时刻的可信数据库起点；更新日志 → 补齐副本之后的更新并区分事务状态；检查点 → 缩短需要检查的日志范围；数据库镜像 → 在主介质故障时提供快速切换的当前副本

四者组成恢复证据链，但镜像不是历史备份，错误也可能同步到镜像

关于数据库镜像，下列哪些说法正确？

正确答案：可以减少部分介质故障下的停机时间、需要承担复制写入和一致性维护成本、可能把逻辑错误同步到镜像、不能替代历史后备副本和恢复演练

镜像主要提高可用性，历史恢复、事务撤销和错误隔离仍需要其他证据与治理

第 7 题 / 共 11 题 · 回想题

为什么动态转储后的介质恢复可能同时需要 UNDO 和 REDO，而不能简单记成“装副本后只 REDO”？

对照答案：动态转储期间事务仍在更新，副本中的不同页面可能对应不同瞬间；有些未提交事务的页面已经进入副本，需要 UNDO，有些已提交更新尚未进入副本，需要 REDO。必须结合转储期间日志、事务状态和恢复算法把副本还原到一致时点，再补齐已提交结果
