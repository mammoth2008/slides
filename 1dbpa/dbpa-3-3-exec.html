第 1 题 / 共 7 题 · 匹配题

将 SELECT 查询子句与主要作用匹配

正确答案：SELECT → 确定结果关系需要输出的列或表达式；DISTINCT → 消除结果中的重复元组；WHERE → 在分组前筛选输入元组；GROUP BY → 按指定属性把元组组织成组；HAVING → 筛选已经形成的组；ORDER BY → 安排结果的显示顺序

各子句作用于查询处理的不同阶段，WHERE 筛行，HAVING 筛组，ORDER BY 只改变结果呈现顺序

要找“平均成绩不低于 80 分的学生”，平均值条件通常应写在哪里？

正确答案：HAVING，因为条件依赖分组后的聚集结果

WHERE 在分组和聚集前筛选行，HAVING 在形成组并计算聚集结果后筛选组

将子查询返回形状与常用外层条件匹配

正确答案：返回一个标量值 → 使用等号或其他标量比较；返回一列值的集合 → 使用 IN 等集合条件；只关心是否存在满足条件的行 → 使用 EXISTS；内层条件引用当前外层元组 → 相关子查询

先判断子查询返回什么，再选择外层运算符；相关子查询会随外层元组重新解释条件
