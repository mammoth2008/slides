第 2 题 / 共 7 题 · 匹配题

将记录表示方法与主要取舍匹配

正确答案：定长字段布局 → 定位简单，但可变数据可能浪费空间或受限；长度标记 → 能表示可变长度字段，但读取时要解析长度；偏移量目录 → 可直接定位字段起点，但需要额外目录空间；字段分离或溢出存储 → 主记录更紧凑，但读取完整对象可能增加 I/O

记录表示在空间利用、随机定位和更新移动成本之间取舍

第 3 题 / 共 7 题 · 匹配题

将关系表组织方式与适用特点匹配

正确答案：堆组织 → 插入方便，按任意条件查询常需扫描；顺序组织 → 按排序属性访问和范围扫描方便，插入维护更复杂；多表聚簇 → 经常连接的相关记录靠近存放，其他访问可能更分散；哈希组织 → 按哈希键等值定位快，范围访问不自然

基础组织决定记录的物理邻近和主要访问路径，不同工作负载的收益方向不同

稀疏主索引为什么要求数据文件按索引属性有序？

正确答案：索引只保存部分块入口，需要从最近入口顺序查到目标记录

有序数据使一个索引项能够代表后续一段记录；无序属性通常需要更稠密的辅助入口

第 5 题 / 共 7 题 · 匹配题

将基础索引类型与查找路径匹配

正确答案：稠密索引 → 每个搜索码值或记录都有索引入口；稀疏索引 → 只为部分搜索码值或数据块保存入口；多级索引 → 对过大的索引再建立上层索引以减少查找块数；辅助索引 → 为非排序属性建立额外入口，重复值可指向指针桶

索引密度和层级决定空间、I/O 与维护方式，辅助索引不要求数据文件按该属性排序

决定使用辅助索引还是顺序扫描时，应考虑哪些因素？

正确答案：条件选择性和预计命中比例、表和索引规模、回表访问的随机 I/O 成本、插入、删除和索引键修改频率、查询需要返回的列

低选择性或需要读取大量数据时，扫描可能更便宜；优化器应比较完整访问代价
