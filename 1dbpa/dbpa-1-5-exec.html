第 1 题 / 共 7 题 · 匹配题

将体系结构名称与它主要改变的观察维度匹配

正确答案：集中式数据库系统 → 主要组件集中在同一台计算机；客户—服务器结构 → 客户端与数据库服务器按请求路径分工；并行数据库系统 → 一个任务由多个处理单元同时处理；分布式数据库系统 → 数据物理分布在多个网络节点并保留场地协作；云数据库系统 → 数据库能力通过云环境和网络服务交付

这些名称来自组件位置、通信路径、任务处理、数据节点和服务交付等不同维度，可以在同一系统中叠加

第 2 题 / 共 7 题 · 单选题

关于 C/S 与 B/S 的关系，下列哪项说法正确？

正确答案：C/S 描述客户端与服务器的协作关系，B/S 是浏览器作为客户端的常见实现

C/S 是客户端与服务器的上位协作关系，客户端可以是桌面应用、移动应用或浏览器；B/S 只是浏览器作为客户端时的常见实现，三层是其中一种常见部署方式

第 3 题 / 共 7 题 · 排序题

按三层结构中一次查询请求的往返顺序排列

  1. 应用服务器处理业务逻辑并请求数据库服务器
  2. 应用服务器整理结果并返回浏览器
  3. 浏览器把请求发送给应用服务器
  4. 数据库服务器通过 DBMS 访问数据并返回结果

正确答案：浏览器把请求发送给应用服务器 → 应用服务器处理业务逻辑并请求数据库服务器 → 数据库服务器通过 DBMS 访问数据并返回结果 → 应用服务器整理结果并返回浏览器

三层结构把界面、业务逻辑和数据库服务分开，浏览器通常不直接访问数据库

第 4 题 / 共 7 题 · 单选题

一个系统使用多台服务器共同执行查询，能否仅凭这一点断定它是分布式数据库？

正确答案：不能，还要判断数据是否跨节点分布、是否存在场地自治及全局协作

多个处理单元可能只是并行执行；分布式数据库强调数据跨节点和局部／全局协作边界

第 5 题 / 共 7 题 · 多选题

云数据库带来按需服务后，哪些问题仍需要设计和管理？

正确答案：身份、权限与数据安全、网络延迟和故障边界、资源成本与容量策略、运维责任和服务边界

云服务改变资源获取和管理方式，但不会自动消除安全、网络、成本、一致性和业务责任问题

第 6 题 / 共 7 题 · 匹配题

将场景变化与最直接的体系结构判断轴匹配

正确答案：把桌面程序改为浏览器、应用服务器和数据库服务器 → 请求路径与组件分层；把一个大型扫描拆给多个处理单元同时执行 → 任务并行；把各校区数据放在本地节点并支持全局查询 → 数据跨节点与场地协作；通过云服务按需扩缩数据库资源 → 服务交付与资源供给

先识别变化的维度，再判断哪些体系结构名称可以同时成立，避免把名称当成互斥等级

三个校区各自维护本地教学数据，全校查询需要跨校区汇总；系统部署在云上，并用多个处理单元加速统计。这个系统可以同时使用哪些体系结构描述？分别说明依据
