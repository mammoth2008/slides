第 1 题 / 共 7 题 · 匹配题

将关系模型术语与其含义匹配

正确答案：域 → 一组具有相同数据类型的允许值集合；笛卡儿积 → 从多个域中各取一个值形成的所有可能组合；元组 → 关系中的一行；属性 → 关系中有名称的一列；分量 → 元组在某个属性上的取值；关系 → 笛卡儿积中有业务意义的有限子集

域先限定允许值，笛卡儿积给出所有可能组合，关系再从中选出有意义的元组

第 4 题 / 共 7 题 · 匹配题

将关系对象与其形成方式匹配

正确答案：基本关系 → 实际存在并由数据库保存的基本表；查询结果 → 关系运算临时产生的结果关系；视图 → 保存查询定义并向用户呈现的导出关系

三者都可表现为关系，但来源、保存方式和生命周期不同

第 5 题 / 共 7 题 · 匹配题

将码相关术语与定义匹配

正确答案：候选码 → 按业务规则能够唯一标识元组的最小属性集；主码 → 从候选码中选定用于主要标识元组的一个码；主属性 → 至少出现在一个候选码中的属性；非主属性 → 不出现在任何候选码中的属性

候选码是否成立依赖业务规则，不能只根据当前样例数据恰好不重复来判断

给 Student 关系增加一条学生记录，关系模式是否随之改变？

正确答案：不改变，只是关系实例发生变化

关系模式描述属性、域映像和约束，是型；某一时刻的元组集合是关系实例，是值

当前 SC 表中每个学生对每门课程只有一条记录，因此 Sno 与 Cno 的组合不重复。为什么这还不足以证明它永远是候选码？如果业务允许重修，应怎样重新判断？
