将数据更新语句与它对关系实例的主要作用匹配

正确答案：INSERT → 增加一个或一组新元组；UPDATE → 修改目标集合中已有元组的属性值；DELETE → 删除目标集合中的元组但保留表定义

三类语句改变关系实例的方式不同，都必须先确定目标集合并检查约束

执行 INSERT SELECT 前，应检查哪些事项？

正确答案：目标列数与查询结果列数是否一致、对应列的数据类型是否兼容、查询结果是否可能违反主码、外码或业务约束、是否会插入预期数量的元组

INSERT SELECT 按位置对应目标列和查询结果，列名不必相同，但形状、类型、约束和影响范围必须核对

第 5 题 / 共 7 题 · 排序题

按安全执行数据更新的顺序排列

  1. 检查实际影响行数、关键数据和完整性结果
  2. 在适当事务边界内执行 INSERT、UPDATE 或 DELETE
  3. 用 SELECT 预览与 WHERE 或子查询相同的目标集合
  4. 估计并核对预期影响行数和约束风险

正确答案：用 SELECT 预览与 WHERE 或子查询相同的目标集合 → 估计并核对预期影响行数和约束风险 → 在适当事务边界内执行 INSERT、UPDATE 或 DELETE → 检查实际影响行数、关键数据和完整性结果

“先预览、后变更、再复查”能减少条件错误和批量误操作造成的损失

第 6 题 / 共 7 题 · 单选题

DELETE FROM Student 与 DROP TABLE Student 的根本差异是什么？

正确答案：DELETE 删除元组并保留表结构，DROP TABLE 删除表对象

DELETE 改变关系实例，DROP TABLE 改变数据库模式；两者的依赖和恢复风险不同
