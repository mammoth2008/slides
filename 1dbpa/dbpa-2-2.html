关系操作分为查询与更新

关系操作包括查询和更新；SQL 还把定义、操纵和控制纳入同一语言

查询 Query

从已有关系中得到所需的结果

例如查询信息管理专业的学生

更新 Update

改变关系中的元组或属性值

包括插入、删除和修改

Takeaway

查询回答“现在有什么”，更新改变“数据库中保存什么”

关系操作一次处理一个集合

成组处理，就是把所有记录一次读进内存吧？

关系模型把成组数据处理作为基本操作方式

处理方式逻辑操作单位学习重点
成组处理 set-at-a-time一组元组组成的关系一次处理一个关系集合
逐条处理 record-at-a-time一条记录，或沿记录路径逐步处理一次处理一条记录

成组处理描述逻辑操作单位，不规定 RDBMS 的物理执行方式；图示用 Cno=81002 筛选说明输入和输出，不把成组处理等同于选择操作

Takeaway

操作对象、结果和中间结果都可以是关系，所以复杂查询可以继续组合

基本操作与导出操作回答不同问题

操作名称用于识别功能，形式化表达式还需要明确运算符和输入输出

操作代数位置主要问题学生选课中的例子
选择基本操作（1/5）哪些元组满足条件找出选修 81002 的记录
投影基本操作（2/5）保留哪些属性只保留学号和姓名
并、差基本操作（3—4/5）合并或排除哪些同型关系合并名单 / 找仅在一方的学生
笛卡儿积基本操作（5/5）所有配对组合是什么形成可能配对后再筛选
连接导出操作（1/3）按相关属性组合哪些关系按 Sno 连接 Student 与 SC
除、交导出操作（2—3/3）满足全部条件 / 同时属于两组修满全部课程 / 找共同名单
Takeaway

选择、投影、并、差和笛卡儿积是 5 种基本操作；连接、除和交可由它们导出。这里的“选择”不等于 SQL 的 SELECT 关键字

OPERATION JUDGMENT

关系代数：用运算表达查询

关系代数说明如何通过关系运算得到查询结果

运算对象

关系是关系代数的输入

运算过程

对关系施加集合运算或专门的关系运算

运算结果

结果仍然是关系，可以继续参与下一步运算

例如 Student 经过选择或投影得到查询结果关系；“怎样运算”是抽象表达，不指定文件扫描或索引路径

RELATIONAL ALGEBRA
DBPA | CH02 | 2.2 | 2.2.2

关系演算：用谓词表达查询

关系演算说明结果应满足什么逻辑条件，不要求用户写出运算步骤

元组关系演算

用元组变量指代整行，并用谓词表达条件

域关系演算

用域变量表示属性值，并用谓词表达条件

Takeaway

关系代数偏向“怎样运算”，关系演算偏向“满足什么条件”

RELATIONAL CALCULUS
DBPA | CH02 | 2.2 | 2.2.2

SQL：关系数据库的综合数据语言

SQL 是综合数据语言，不只提供查询

DQL

Data Query Language：从已有关系中查询结果

DDL

Data Definition Language：定义或修改关系结构和数据库对象

DML

Data Manipulation Language：插入、删除和修改关系数据

DCL

Data Control Language：管理访问权限和数据控制

Takeaway

这些功能由具体 SQL 语句实现

10/15
SQL LANGUAGE
DBPA | CH02 | 2.2 | 2.2.2

关系完备性衡量语言能表达什么查询

能表达关系代数所能表达的全部查询，才称为具有关系完备性

语言表达方式语言层次
关系代数对关系进行运算抽象查询语言
元组关系演算用元组变量和谓词抽象查询语言
域关系演算用域变量和谓词抽象查询语言
SQL查询、定义、操纵与控制实际综合语言；查询能力达到关系完备
Takeaway

三种抽象查询语言表达能力等价；SQL 具备关系完备的查询能力，并提供定义、操纵和控制功能

11/15
RELATIONAL COMPLETENESS
DBPA | CH02 | 2.2 | 2.2.2

SQL 查询描述目标，RDBMS 选择路径

同一个查询可以有多条正确的存取路径

用户描述查询目标→RDBMS 选择执行计划→返回结果

用户说明目标

给出需要的关系结果和筛选条件，不必逐步写出访问文件的动作

系统比较路径

RDBMS 的优化机制可以比较顺序扫描、索引扫描和不同的连接顺序

结果保持一致

不同执行计划应得到相同的查询结果，但所需时间和资源可能不同

Takeaway

非过程化不等于没有执行过程，而是把存取路径选择交给 RDBMS

同一个查询，竟然可以有多条正确执行路径？

NONPROCEDURAL QUERY
DBPA | CH02 | 2.2

从请求到存取路径判断关系操作

关系操作先区分请求类型，再区分处理粒度、操作类别和语言能力

查询与更新

查询产生结果；更新包括插入、删除和修改

成组处理与闭包

set-at-a-time 以关系为逻辑单位；结果和中间结果仍是关系

基本与导出

基本操作五种：选择、投影、并、差、笛卡儿积；导出操作三种：连接、除、交

语言与能力

关系代数用运算，关系演算用谓词；关系完备性评价查询能力，SQL 提供综合功能

Takeaway

先判断请求类型，再区分抽象表达方式与实际 SQL 功能；SQL 查询通常不要求用户指定存取路径
