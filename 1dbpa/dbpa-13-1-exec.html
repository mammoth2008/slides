第 2 题 / 共 11 题 · 匹配题

将系统层次与主要职责匹配

正确答案：应用层 → 提供业务界面并提交 SQL 或数据库调用；语言处理层 → 分析、检查、优化并生成执行方案；数据存取层 → 把计划落实为元组和事务操作；数据存储层 → 管理缓冲区、文件、页和存取路径；操作系统 → 提供设备、文件和物理 I/O 基础

稳定的层次接口使上层不必直接依赖具体设备和物理布局

第 3 题 / 共 11 题 · 排序题

一条带条件 SELECT 在 DBMS 中的典型执行路径如何排列？

  1. 优化器生成并选择执行计划
  2. 应用提交 SQL 请求
  3. 结果逐层返回应用
  4. 数据存储层通过缓冲区和文件路径取得页面
  5. 语言处理层用数据字典完成名称、类型和权限检查
  6. 数据存取层调用记录与事务原语

正确答案：应用提交 SQL 请求 → 语言处理层用数据字典完成名称、类型和权限检查 → 优化器生成并选择执行计划 → 数据存取层调用记录与事务原语 → 数据存储层通过缓冲区和文件路径取得页面 → 结果逐层返回应用

名称和权限通过后才访问所请求的业务记录；目录读取可能更早发生，不能说此前必无物理 I/O

第 5 题 / 共 11 题 · 匹配题

将操作尺度与示例匹配

正确答案：集合请求 → 查询某专业的全部学生；单记录操作 → 取得下一条满足条件的元组；页面／缓冲区操作 → 把包含目标记录的页装入内存；物理文件块读写 → 操作系统执行文件块读取，可能命中文件缓存或访问设备

同一查询在不同层次呈现为不同尺度的请求，接口负责逐层转换
