按 SQL 形成共同语言的基本发展顺序排列

  1. 语言名称调整为 SQL
  2. 在 System R 项目中设计并实现 SEQUEL
  3. ANSI 与 ISO 推动 SQL 标准化
  4. 各 DBMS 实现标准子集并提供厂商扩展

正确答案：在 System R 项目中设计并实现 SEQUEL → 语言名称调整为 SQL → ANSI 与 ISO 推动 SQL 标准化 → 各 DBMS 实现标准子集并提供厂商扩展

SQL 从关系数据库原型中的实验语言发展为标准化共同语言，具体产品仍可能只实现子集或增加扩展

第 2 题 / 共 7 题 · 匹配题

将 SQL 语言特征与其含义匹配

正确答案：功能综合 → 在一套语言中提供定义、查询、操纵和控制能力；非过程化 → 用户说明需要什么结果，不必指定具体存取路径；面向集合 → 一次逻辑操作处理一组元组；统一使用方式 → 交互、驱动调用和嵌入式使用共享核心语句；简洁易学 → 用数量有限的核心动词组织常见任务

五个特征共同降低了关系数据库的使用门槛，但 DBMS 仍负责复杂的物理执行

将 SQL 请求与功能类别匹配

正确答案：CREATE TABLE Student → 数据定义 DDL；SELECT 查询学生姓名 → 数据查询 DQL；UPDATE 修改学生专业 → 数据操纵 DML；GRANT 授予查询权限 → 数据控制 DCL

先判断请求是在建立结构、读取结果、改变数据还是管理权限

第 4 题 / 共 7 题 · 匹配题

将 SQL 使用方式与典型场景匹配

正确答案：交互式 SQL → 用户在数据库客户端直接输入语句；API／驱动调用 → Java 或 Python 程序通过数据库驱动执行 SQL；嵌入式 SQL → SQL 语句嵌入宿主语言并经预处理或编译

三种方式的调用环境不同，但都可以使用 SQL 的核心关系操作能力

第 5 题 / 共 7 题 · 匹配题

将数据库对象与三级模式层次匹配

正确答案：面向特定用户的普通视图 → 外模式；基本表及其逻辑约束 → 模式；存储文件和索引 → 内模式

基本表是逻辑关系对象，不等同于物理文件；普通视图通常为用户提供局部逻辑入口

第 7 题 / 共 7 题 · 回想题

应用程序只写“查询符合条件的学生”，却不指定扫描文件还是使用索引。这里体现了 SQL 和三级模式的哪些思想？

对照答案：SQL 的非过程化特征让用户描述目标结果，RDBMS 决定访问路径；基本表和视图属于逻辑层，文件和索引属于内模式。模式／内模式映像及 DBMS 的执行选择把逻辑查询与物理存储隔离，因此更换存取路径时同一逻辑查询通常不必改写
