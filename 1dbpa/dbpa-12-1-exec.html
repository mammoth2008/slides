将并发异常与最小操作特征匹配

正确答案：丢失修改 → 两个事务基于同一旧值写回，后写覆盖先写；脏读 → 一个事务读取了另一未提交事务的修改；不可重复读 → 同一事务两次读取同一行得到不同已提交值；幻读 → 同一事务重复执行范围查询时出现或消失满足条件的行

四类异常的区别在于被覆盖、读到未提交值、同行变化或结果集合成员变化

第 2 题 / 共 7 题 · 匹配题

将标准隔离级别与其最低保证匹配

正确答案：READ UNCOMMITTED → 可能出现脏读、不可重复读和幻读；READ COMMITTED → 防止脏读，但仍可能不可重复读和幻读；REPEATABLE READ → 防止脏读和不可重复读，标准层面仍可能幻读；SERIALIZABLE → 目标是让并发结果等价于某个串行次序

隔离级别描述保证，不同 DBMS 的具体实现可能使用锁或多版本技术，不能只凭名称推断内部机制

第 5 题 / 共 7 题 · 匹配题

将三级封锁协议与主要规则匹配

正确答案：一级封锁协议 → 修改前加 X 锁并保持到事务结束，主要防止丢失修改；二级封锁协议 → 在一级基础上，读取前加 S 锁，读完可释放，进一步防止脏读；三级封锁协议 → 读取与修改都加相应锁并保持到事务结束，进一步防止不可重复读

协议差异不仅在是否加锁，还在锁的持有时间；幻读还涉及谓词或范围保护

选择隔离强度时应考虑哪些因素？
