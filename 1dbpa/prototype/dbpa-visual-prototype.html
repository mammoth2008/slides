SQL Template
03 / QUERY PATH

把 SQL 页做成问题、语句、结果

Question

查询每位玩家在比赛中使用的英雄，并按击杀数排序。

  1. 先找到参与记录。
  2. 再连接用户表和英雄表。
  3. 最后排序形成结果表。
SELECT u.UserName, h.HeroName, mp.Kills
FROM MatchParticipation mp
JOIN Users u ON mp.UserID = u.UserID
JOIN Heroes h ON mp.HeroID = h.HeroID
ORDER BY mp.Kills DESC;

12 / TRANSACTION CONTROL

事务机制用时间线表达

恢复和并发不是列表知识点，而是状态如何变化、冲突如何发生、系统如何保证 ACID。

BEGIN

事务开始，日志记录操作意图。

WRITE

更新缓冲区，可能遭遇故障或并发冲突。

COMMIT

提交后改变必须持久保存。

REDO / UNDO

恢复系统把数据库带回正确状态。
