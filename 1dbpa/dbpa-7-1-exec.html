第 3 题 / 共 7 题 · 匹配题

将需求类别与选课系统中的示例匹配

正确答案：信息要求 → 需要保存学生、课程、教学班和选课记录；处理要求 → 学生提交申请，教师审核并生成结果；安全性要求 → 学生只能查看自己的申请，教师只能处理授权教学班；完整性要求 → 同一学生不能重复申请同一教学班且人数不能超限

需求分析不仅列数据字段，还要说明处理、权限和合法状态

第 4 题 / 共 7 题 · 匹配题

将调查方法与较适合获得的证据匹配

正确答案：访谈 → 理解角色目标、例外和隐含业务规则；问卷 → 从大量用户收集可比较的需求反馈；跟班观察 → 发现实际操作与书面流程的差异；查阅单据和制度 → 获取已有字段、编码和正式规则；原型讨论 → 让用户对界面、流程和边界进行具体反馈；数据分析 → 检查现有数据量、质量、分布和异常

不同方法回答不同证据问题，复杂项目通常需要组合使用并交叉验证

第 5 题 / 共 7 题 · 匹配题

将数据字典条目类型与记录内容匹配

正确答案：数据项 → 单个字段的含义、类型、取值和来源；数据结构 → 多个数据项组成的业务记录；数据流 → 数据从哪个处理或角色流向哪里；数据存储 → 持久保存的数据集合及其边界；处理过程 → 输入如何经过业务规则产生输出

五类条目把调查证据组织为可追踪的设计输入，并连接后续实体、属性、联系和约束
