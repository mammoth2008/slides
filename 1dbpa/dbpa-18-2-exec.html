第 2 题 / 共 7 题 · 匹配题

将准入模式与典型治理边界匹配

正确答案：公有链 → 开放参与，读写和记账主要由公开协议约束；联盟链 → 多个获授权组织共同决定成员、权限和记账规则；私有链 → 单一组织控制节点准入、读写范围和内部治理

开放程度反映信任与治理选择，不代表技术先进程度；具体共识和性能仍取决于实现

第 3 题 / 共 7 题 · 匹配题

将九层功能架构归并后的责任组与主要功能匹配

正确答案：资源层 → 提供计算、存储、网络和密码设备等运行资源；节点基础层 → 承担点对点通信、节点发现和数据传播；可信状态层 → 组织账本数据、密码证明、共识和状态一致性；业务执行层 → 执行智能合约并向应用提供业务接口；治理服务层 → 管理身份、权限、监控、运维和跨组织规则

分组用于澄清责任边界，不表示所有平台都必须按同样名称实现九个物理层

第 4 题 / 共 7 题 · 匹配题

将智能合约的事件—条件—动作要素与含义匹配

正确答案：事件 → 触发一次合约处理的链上交易或可信输入；条件 → 根据当前状态和规则判断是否允许继续执行；动作 → 在验证通过后产生确定的状态变化或调用结果

ECA 描述执行逻辑；事件来源、执行确定性、权限和升级治理仍需单独设计

智能合约收到“货物已送达”的外部数据后，链上共识能够直接证明什么？

正确答案：只能证明网络按协议接受了这条输入及其执行结果，不能自动证明线下送达事实真实

共识解决节点对数字记录的共同接受问题，外部事实真实性仍取决于预言机、身份、证据和治理

第 6 题 / 共 7 题 · 多选题

为什么去中心化、安全和效率通常需要工程取舍？

正确答案：更多参与者和副本会增加传播与验证成本、更强的拜占庭容错常需要更多消息或资源证明、更快确认可能缩小参与范围或采用更强信任假设、所有节点重复保存和执行会增加存储与计算开销

系统必须在参与开放度、故障假设、验证成本、延迟和吞吐之间选择，不能脱离场景宣称三者同时最大化
