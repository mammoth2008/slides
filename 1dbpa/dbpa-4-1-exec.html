第 3 题 / 共 7 题 · 匹配题

将授权选项与它控制的传播能力匹配

正确答案：WITH GRANT OPTION → 允许接收者继续转授相应对象权限；WITH ADMIN OPTION → 允许角色成员继续管理该角色的成员关系；普通 GRANT → 授予权限但默认不允许继续传播；REVOKE → 回收已经授予的权限或角色关系

对象权限传播和角色管理传播属于不同授权图，回收后果还要结合标准与具体 DBMS 行为判断

第 5 题 / 共 7 题 · 匹配题

将存取控制方式与决策特点匹配

正确答案：自主存取控制 DAC → 对象拥有者或授权者按权限图决定访问与传播；强制存取控制 MAC → 系统按主体、客体密级和固定规则决定是否放行

DAC 与 MAC 可以叠加；即使其中一层允许，另一层拒绝时访问仍不能通过
