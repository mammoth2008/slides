将删除被引用学生时的参照动作与结果匹配

正确答案：RESTRICT／NO ACTION → 存在引用记录时拒绝删除；CASCADE → 同时删除或更新依赖的参照记录；SET NULL → 把外码设为空，前提是外码列允许 NULL 且业务语义合理

第 6 题 / 共 7 题 · 匹配题

将约束机制与适合表达的规则匹配

正确答案：NOT NULL → 某列必须提供值；UNIQUE → 某列或属性组中的非重复要求；CHECK → 当前行内可判断的取值或属性组合规则；DOMAIN → 在支持该功能的 DBMS 中集中复用取值规则；ASSERTION 概念 → 表达可能跨表的数据库级断言，但产品支持有限

选择机制时要考虑约束范围、NULL 语义、维护方式和目标 DBMS 的能力

第 7 题 / 共 7 题 · 回想题

订单表的 CustomerId 外码在删除客户时应选 RESTRICT、CASCADE 还是 SET NULL？说明如何作出决定

对照答案：先判断订单是否必须永久保留、是否允许失去客户归属、删除客户是物理删除还是停用，以及法律审计要求。通常历史订单不应随客户级联删除；如果订单必须保留且仍需归属，可拒绝删除或改用停用状态；只有业务允许匿名订单且外码可空时才考虑 SET NULL。选择应来自业务生命周期，而不是语法便利
