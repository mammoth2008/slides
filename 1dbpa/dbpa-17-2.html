价格 × 数量 × 税率：四种执行方式

四种做法减少的工作不同：找字段、反复调用函数、中间结果或解释执行

  1. 01行处理逐条访问记录属性并计算；它重复的是记录迭代、属性定位和函数调用，不是 SQL 语法解析
  2. 02列处理批量访问整列，减少重复函数调用，但可能产生较大的临时列空间
  3. 03向量化按 Cache 与工作负载选择连续数据块，保留列处理批量优势并降低中间结果代价
  4. 04实时编译把热点表达式编译为机器码或中间级字节码，减少记录解析和函数调用；是否采用取决于系统实现

QUERY MODELS
DBPA | CH17 | 17.2 | 17.2

Cache line、TLB、NUMA 影响快慢

CSB+、Radix 分区和 NUMA-aware 排序合并分别减少不同的等待

技术关注的硬件问题直观收益
CSB+ 树按 Cache line 连续组织节点组，减少指针和地址跳转缓存友好的索引访问
Radix 哈希连接分区后让哈希表更接近 Cache 容量，减少 Cache 和 TLB 失效分区探测局部性更好；付出分区时间和空间
NUMA-aware 排序合并先在节点内局部排序，再处理跨节点归并减少远程访问；仍需承担归并协调
Takeaway

硬件敏感算法通过布局、分区和归并改善局部性；收益取决于数据规模、带宽和跨节点竞争

HARDWARE CONSCIOUS
DBPA | CH17 | 17.2 | 17.2

同时改库存：锁、乐观、无锁要处理冲突

无锁结构没有锁，就不会有同步和冲突成本了吧？

锁粒度、乐观并发控制、无锁结构和快照隔离分别改变协调方式

锁粒度

较大粒度可减少锁管理元数据，但可能扩大冲突范围；短事务不等于低冲突

乐观并发控制

乐观并发控制在低冲突负载下可减少等待；提交检查失败时需要重试或回滚

无锁结构

无锁结构用原子操作降低锁竞争，但仍需处理同步、可见性和内存回收成本

快照隔离

快照隔离为 OLAP 只读查询提供一致视图；它是并发隔离机制，不是恢复快照

CONCURRENCY
DBPA | CH17 | 17.2 | 17.2

日志、检查点与并行恢复

并行恢复只把日志切开就够了吗？

快照隔离处理并发读视图；恢复根据日志和检查点重建可用状态

  1. 01日志写入非易失性介质，为后续重做提供依据
  2. 02检查点保存恢复基线，仍需结合日志重做；它不一定是完整可重启状态
  3. 03预提交或组提交降低提交等待，但不消除日志成本
  4. 04崩溃后可按策略优先恢复热点数据，其他数据随后装载
  5. 05数据分区与日志分区保持对应，多核心才能更安全地并行恢复

并行恢复可以缩短等待，但持久性写入、检查点、重做顺序和并行协调仍有代价

8/14
THREE OPTIONS
DBPA | CH17 | 17.2 | 17.2

用点查、改单和地区汇总决定三种做法

分别写订单放在哪里、谁执行点查和汇总、旧接口改多少、每份副本何时更新

混合引擎

混合引擎保留已有订单系统接口，可增加内存行／列路径；副本同步和资源隔离仍有代价

独立系统

独立系统适合事务与分析都要求低延迟且愿意重做布局、索引和恢复；代价是迁移数据并修改运维脚本

GPU 引擎

区域销售汇总等规则、大批量的分析适合 GPU；数据传输、控制流和恢复路径必须可控

Takeaway

不要只按产品名称选择：先统计点查、改单和地区汇总各占多少，再计算迁移工作和 CPU／GPU 传输时间

IMPLEMENTATION EXAMPLES
DBPA | CH17 | 17.2 | 17.2

DRAM／NVM 到 CPU／GPU：都经互连

存放位置、计算设备和传输路径会一起影响查询时间与崩溃恢复

存储层

DRAM 与 NVM 按访问频率、容量、成本和持久性分工；数据放置本身有代价

计算层

CPU、GPU、FPGA 等处理器按算子和并行度分工；并非所有查询都适合加速

互连层

PCIe、RDMA、NVLink 等可降低传输代价，但不能消除数据移动、同步和恢复问题

异构数据库仍需同时优化数据放置、查询执行、恢复和资源调度

FUTURE HARDWARE

行列同系统：新订单何时可见

行存和列存放在同一个系统里，就自动成为 HTAP 了吗？

除了行列布局，还要说明订单何时同步到分析端，以及长查询能占用多少资源

存储融合

事务行存与分析列存可以并存或转换；行列适配是典型路线，不是 HTAP 的唯一形式

数据可见性

日志、副本、提交语义和查询调度共同决定分析何时看到最新事实

资源隔离

长分析不能挤占短事务；CPU／GPU 调度能缓解冲突，但不保证零延迟

Takeaway

HTAP 不保证只存一份数据、报表始终读到刚提交的订单，也不保证长查询自动避开下单资源
