WITH 给本条查询的中间结果命名

WITH 定义公用表表达式 Common Table Expression，简称 CTE

09WITH class_avg AS (
  SELECT ClassNo, AVG(Grade) AS avg_grade
  FROM SC
  WHERE Cno = '81001' AND Term = '2026-1'
  GROUP BY ClassNo
)
SELECT a.avg_grade - b.avg_grade AS difference
FROM class_avg a CROSS JOIN class_avg b
WHERE a.ClassNo = '01' AND b.ClassNo = '02';
Takeaway

class_avg 得到 01→85、02→75，相减得 10；名称仅在本条语句有效，不创建长期表，也不保证物化或提速

递归 CTE 的种子项与递归项

种子项从 81003 出发，递归项用上一轮课号查找它的先修课

09WITH RECURSIVE prereq(cno) AS (
  SELECT Cpno FROM Course
  WHERE Cno = '81003' AND Cpno IS NOT NULL
  UNION
  SELECT c.Cpno FROM Course c
  JOIN prereq p ON p.cno = c.Cno
  WHERE c.Cpno IS NOT NULL
)
SELECT cno FROM prereq ORDER BY cno;
Takeaway

本查询结果按课号排序为 81001、81002。UNION 对整行去重；改为 UNION ALL 后，重复行可继续参与下一轮

练习：先修关系出现环，查询还会停吗？

把 81001 的 Cpno 从 NULL 改为 81003，其他记录不变

81003→81002→81001→81003→…

CTE 只有课号一列

UNION 不再加入已出现的课号，因此会停止；结果却包含起点 81003，说明先修关系有误

增加不断变化的层数

若结果行是“课号、层数”，同一课号配上新层数仍是不同的行，UNION 去重也不能保证消除环

Takeaway

需要防止沿当前路径再次访问同一课号，并检查先修关系是否有效；限制递归层数是保护措施，不证明结果完整
