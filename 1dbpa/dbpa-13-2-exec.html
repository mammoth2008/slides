第 3 题 / 共 7 题 · 匹配题

将记录原语与典型作用匹配

正确答案：FIND → 建立满足条件的记录定位或扫描状态；GET → 取得当前定位的记录内容；NEXT → 移动到下一个满足条件的记录

记录原语是集合执行计划与底层页面访问之间的接口，具体名称和实现可能因 DBMS 而异

第 4 题 / 共 7 题 · 匹配题

将数据存取子系统与职责匹配

正确答案：记录存取 → 定位、读取和修改记录；事务与封锁 → 管理提交边界和并发冲突；日志 → 保存可恢复的更新证据；排序／合并 → 支持 ORDER BY、连接和分组等操作；路径维护 → 保持表数据与索引等存取路径一致；控制信息 → 保存执行状态和上下文

一次记录更新往往需要多个子系统协作，而不是单独写一个数据页

第 7 题 / 共 7 题 · 回想题

一条视图查询最终为什么会变成 FIND、GET、NEXT，而用户仍只看到集合 SQL？

对照答案：SQL 在逻辑上描述结果集合；语言处理层通过视图消解、优化和逐步束缚，把集合算子转换为数据存取层的记录原语。数据存取层再通过缓冲区和文件接口取得页面与记录。分层隐藏这些迭代细节，使用户可以保持非过程化的集合表达
