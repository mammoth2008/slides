4.1 为什么需要 Workflow

### 从单次回答到持续执行 - 单次 Prompt 适合一次性问题 - 复杂任务往往不是一步完成 - 真正的工作包含规划, 执行, 检查和修正 - Workflow 解决的是多步骤协作问题
![Prompt 与 Workflow 对比图](img/c04/prompt-vs-workflow.svg) #### 从单次 Prompt 到 Workflow
### 只靠 Prompt 为什么不够 - 同一个任务往往要分多步完成 - 上下文一长, 模型容易忽略重点 - 缺少检查点时, 错误会一路累积 - 输出看起来合理, 不等于真的可用
### 只靠 Agent 为什么也不够 - Agent 会执行, 不代表方向总是对 - 没有流程约束时, 容易边做边偏 - 没有验证环节时, 容易 "声称完成" - 越复杂的任务, 越需要结构化流程
### Workflow 的基本作用 - 把复杂任务拆成可管理步骤 - 为每一步设置输入和输出 - 在关键节点加入人工审阅 - 让结果更稳定, 更容易复现
![Workflow 闭环图](img/c04/workflow-loop.svg) #### Workflow 的基本闭环
### 案例: 用 Workflow 自动化生成宣传图片 - 目标: 为一次校园活动批量生成宣传图片 - 输入: 活动主题, 时间地点, 文案要点, 参考风格 - 输出: 多张候选图片, 配套文案和最终定稿 - 关键问题: 怎样稳定地产出可用结果
### 这个任务为什么不能只靠一次 Prompt - 一次生成往往只能得到一个初稿 - 同一主题通常需要多种风格和尺寸 - 结果是否可用, 还要看文字, 版式和场景适配 - 所以它天然需要分步骤执行
### 一个简单 Workflow 的结构 - 第一步: 明确目标和使用场景 - 第二步: 整理文案和视觉要求 - 第三步: 生成多组图片草稿 - 第四步: 筛选并修改候选结果 - 第五步: 输出最终版本并归档
![宣传图片 Workflow](img/c04/media-workflow.svg) #### 宣传图片生成 Workflow
### 哪些步骤适合确定性 - 文件检查 - 格式校验 - 输出路径和命名规则 - 尺寸和比例检查
### 哪些步骤适合生成式模型 - 需求理解 - 风格方案起草 - 图片草稿生成 - 配套文案生成
### 人在 Workflow 中的位置 - 决定目标是否清楚 - 决定风格是否符合场景 - 判断图片和文案是否真的匹配 - 在异常情况下重新设定方向
![人机分工图](img/c04/human-ai-roles.svg) #### 人与 AI 在 Workflow 中的分工
### 用什么工具承载 Workflow - 流程思想先于工具 - 白板, 文档, 表格都能先画出流程 - Coze 适合做低门槛可视化演示 - 但工具界面不能代替方法理解
### 课堂练习一: 把任务改写成 Workflow - 选择前面做过的一个 AI 任务 - 把它拆成 4 到 5 个步骤 - 标出哪些步骤由人判断 - 标出哪些步骤可交给 AI
### 本节结论 - Prompt 解决一次表达 - Agent 解决一次执行 - Workflow 解决持续协作 - 有了 Workflow, AI 才更接近稳定生产力
