### 早期探索 - 依靠人类预设规则产生内容 - 以规则驱动系统为主 - 诞生了人类首个聊天机器人 - 缺乏理解与泛化能力 - 遇到规则库之外的场景系统极易崩溃
![Eliza](img/c01/201computer-scientist-joseph-weizenbaum-with-his-chatbot-eliza-running-on-an-ibm-36-bit-ibm-7094-mainframe-computer.webp) #### ELIZA
### ELIZA - 1967, MIT, Joseph Weizenbaum - 模式匹配与关键字提取 - 通过预设脚本运行 - 最著名的脚本是模拟心理治疗师 - 不理解对话内容的真正语义, 仅作**规则映射** - 伊莉莎效应
### 深度生成模型 - 利用神经网络从数据中提取特征 - 提出**潜在空间**概念, 将图像压缩为语义 - **变分自编码器**实现信息压缩与概率还原 - **生成对抗网络**通过博弈生成逼真内容 - 奠定了现代视觉生成技术的基础
### 潜在空间 (Latent Space) - 高维原始数据经过压缩后形成低维数学表示空间 - 丢弃冗余像素细节 - 保留决定数据本质的核心语义特征 - 使计算机能够进行语义级别的运算与编辑 - 坐标的距离反映数据特征相似度
### 变分自编码器 (VAEs, Variational Autoencoders) - 结合深度学习与概率推断的经典生成模型 - 编码器将输入数据映射为潜空间中的概率分布 - 解码器从概率分布中进行随机采样并重建生成 - 损失函数由重建误差与相对熵组成 - 相对熵即 KL 散度, 其优化目标公式为 $ \mathcal{D}\*{KL}(q\*\phi(z|x) | | p(z)) = -\frac{1}{2} \sum\_{j=1}^{J} (1 + \log(\sigma\_j^2) - \mu\_j^2 - \sigma\_j^2) $
### 生成对抗网络 (GANs, Generative Adversarial Networks) - 由生成器和判别器两个神经网络共同组成 - 生成器负责制造逼真的伪造数据 - 判别器负责区分输入是真实的数据还是伪造的 - 训练过程是一个极小极大博弈过程 - 优化目标公式为 $\min\_G \max\_D V(D, G) = \mathbb{E}\_{x \sim p\_{data}(x)} + \mathbb{E}\_{z \sim p\_z(z)}$
![GAN](img/c01/202eOTTCwC-jGXpbAoc9yVg.png) #### Generative Adversarial Networks
### 自然语言处理的架构突破 - RNN、LTSM 等受限于逐字阅读逻辑 - Transformer 架构引入注意力机制 - **词元化**与**向量嵌入**将文字转化为空间坐标 - **位置编码**为并行计算的文本注入顺序信息 - 多头注意力让模型从多重维度理解上下文
![RNN](img/c01/203rnn.png) #### Recurrent Neural Network
![LSTM](img/c01/204lstm.png) #### Long Short-Term Memory
![Transformer](img/c01/205transformers.png) #### Transformer
### 词元化 (Tokenization) - 将自然语言文本切成可计算最小统计单元 - 词元与自然语言单位不同 - 词元化算法需要取得平衡 - 词元粒度影响模型对语言的理解效率与成本 - 每个独立的词元拥有唯一数字 ID
![Tokenization](img/c01/206tokens.png) #### Tokenization
### 向量嵌入 (Embeddings) - 将离散的词元 ID 映射为连续高维空间中的实数向量 - 空间中每一维隐式代表了某种语义、情感或语法特征 - 神经网络能够通过数学运算处理文字符号 - 语义相近词元的余弦相似度高 - 是大语言模型计算注意力权重的基础 - 是企业搭建知识库检索系统的基础
![Embeddings](img/c01/207embedding.png) #### Embeddings
### 位置编码 (Positional Encoding) - 为并行模型注入序列中词元的绝对或相对位置信息 - 生成特定的数学波形并附加到词元的嵌入向量上 - 使 Transformer 模型可以感知词序 - 偶数维度位置编码 $ PE\_{(pos, 2i)} = \sin(pos / 10000^{2i/d\_{model}}) $ - 奇数维度位置编码 $ PE\_{(pos, 2i+1)} = \cos(pos / 10000^{2i/d\_{model}}) $
![Positional Encoding](img/c01/208positionalencoding.webp) #### Positional Encoding
### 大语言模型的定局 - 根据业务需求分化为三大不同流派 - **仅编码器模型**用于全局理解与信息分类 - 编码器加解码器模型用于翻译与摘要 - **仅解码器模型**用于生成文本回应 - 仅解码器架构成为当前主流
### 编码器 (Encoder) 模型 - 负责阅读理解和提取全局特征的组件 - 采用双向注意力机制, 同时兼顾左右上下文 - 将输入文本转化为含语境信息的隐藏状态向量 - 适合分类、情感分析和意图理解等判别性任务 - 代表性产品为 Google 的 BERT 系列
### 解码器 (Decoder) 模型 - 负责基于已有信息预测并生成新内容的组件 - 采用掩码自注意力机制, 只能看到历史词元 - 自回归方式工作, 根据概率逐字预测下个词元 - 用户提示词直接作为上文被无缝续写 - 具备规模扩展能力和推理效率
![Decoder](img/c01/209gpts.png) #### Decoder Model
### 扩散 (Diffusion) 模型 - 引入模拟物理扩散的破坏与还原机制 - 前向: 向清晰图像逐步添加噪声 - 反向: 训练神经网络逐步去噪 - 结合潜在空间压缩, 降低算力门槛
![Diffusion](img/c01/210diffusion.png) #### Diffusion Model
### 多模态融合 - 实现文本、图像和声音统一处理 - 模型推理与训练成本迅速下降 - 从被动聊天框向主动解决问题演进
![Multimodal Models](img/c01/211_multimodal_models.png) #### Multimodal Models
### 数据表征升维 - 将多媒体数据统一转化为高维向量和词元序列 - 视觉内容压缩映射为视觉词元输入网络 - 单一模型能够跨模态理解复杂上下文 - 从单一感知能力向综合认知系统跃迁
