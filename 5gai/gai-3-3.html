### 从对话到自主执行 - 对话式: 人提出一步需求, AI 返回一步结果 - Agent 式: 人描述目标和边界, AI 自主拆解并逐步执行 - 区别不只在界面, 而在是否形成执行闭环 - Agent 让 AI 从 "代码生成器" 变成 "任务执行者"
### Agent 模式的本质 - 能够读取项目文件和目录结构 - 能够运行命令, 观察执行结果 - 能够根据反馈继续下一步修改 - 核心是 "更会做"
### 信息管理为什么是更底层的问题 - 每个人都需要处理信息 - 获取, 识别, 整理, 使用, 抛弃 - 决策质量取决于信息管理质量 - AI 改变的是这一流程的速度和结构
![信息管理流程图](img/c03/info-management-lifecycle.svg) #### 信息管理流程: 获取, 识别, 整理, 使用, 抛弃
### Agent 的基本执行链路 - **理解目标**: 把模糊任务转成可执行目标 - **拆解步骤**: 确定先做什么, 后做什么 - **读取上下文**: 查看代码, 配置, 日志和相关文件 - **执行修改**: 修改文件, 新增文件, 运行命令 - **验证结果**: 检查功能是否真的完成 - **失败修正**: 根据错误继续调整
![Agent 执行闭环图](img/c03/agent-execution-loop.svg) #### Agent 执行闭环: 读取, 执行, 验证, 修正
### Agent 对信息管理流程的影响 - **获取信息**: 更快检索和汇总材料 - **识别价值**: 先做初步分类和筛选 - **整理信息**: 生成结构化摘要和草稿 - **使用信息**: 转成报告, 页面, 表格和方案 - **抛弃信息**: 识别重复, 过时和低价值内容
### 案例: 从数据获取到分析摘要 - 目标: 生成一份可阅读的数据分析初稿 - 输入: 多个网页, CSV, Excel 或文本材料 - 输出: 清洗后的数据表, 图表摘要和结论草稿 - 这个案例展示完整信息管理链条
![数据分析流程图](img/c03/data-analysis-pipeline.svg) #### 数据分析流程: 采集, 清洗, 汇总, 摘要, 人工判断
### Agent 适合做什么 - 收集多个来源的数据 - 统一字段和格式 - 识别缺失值和重复项 - 生成初步图表和摘要 - 输出待审阅的分析草稿
### 人必须做什么 - 判断数据来源是否可信 - 判断字段含义是否被正确理解 - 判断异常值是否应删除 - 判断图表结论是否真的成立 - 判断这份摘要能否支持决策
### 什么任务适合 Agent - 目标明确, 成功标准清楚 - 项目上下文已经存在 - 结果可以验证, 如页面, 测试, 报表, 文件输出 - 修改范围可控, 不需要频繁改变方向
### 什么任务不适合 Agent - 需求本身还没想清楚 - 业务边界模糊, 需要大量判断 - 没有验证标准, 只能凭感觉说 "差不多" - 一旦出错代价很高
### AI 让信息管理变强的地方 - 降低整理成本 - 提高初步归纳速度 - 支持多来源材料汇总 - 让中间结果更容易复用
### AI 让信息管理变危险的地方 - 容易把噪声也整理得很漂亮 - 容易把错误内容包装成高质量信息 - 容易让人跳过判断环节 - 容易让低价值信息大量堆积
### 人在 Agent 模式中的角色 - 定义目标, 而非列出步骤 - 提供约束, 如禁止事项, 输出格式, 文件范围 - 观察执行链路, 判断它有没有跑偏 - 审查结果质量, 决定是否接受 - 在例外情况出现时主动介入
### Skills: 从 Prompt 到可复用能力 - 一次 Prompt 只能解决一次问题 - 同类任务反复出现时, 临时 Prompt 会越来越低效 - Skill 是把成功经验整理成可复用结构 - 它让 AI 不必每次都从零开始猜
### Agent 与 Skill 的关系 - Agent 负责理解目标和组织执行 - Skill 提供局部稳定能力 - 没有 Skill 的 Agent, 容易每次都临场发挥 - Skill 越清晰, Agent 的输出越稳定

### V4: 用 Agent 模式完成一个自动化任务 - 示例任务: 每周一自动生成上周学习报告 - 明确目标, 输出路径, 禁止事项和验证要求 - 记录 Agent 的执行过程, 而不只看最后结果 - 评估: 这个任务是否真的适合 Agent
### V4 观察要点 - Agent 是否准确理解了任务边界 - 它是否先读代码再修改, 还是直接猜 - 它有没有做验证, 还是只声称完成 - 你在什么时刻必须介入
### 课堂练习五: 能力反思 - 以案例 A 为例
### V5: 对比 AI 生成 vs 手工编写 - 选一个功能, 同时观察 AI 实现和人工实现 - 对比时间成本, 修改成本和结果质量 - 反思: 在这个任务里, AI 做了什么, 你做了什么 - 总结: 你的价值体现在哪一步
### V5 观察要点 - AI 输出有多少能直接用 - 修改 AI 的成本是否低于从零写 - 你最重要的作用是写代码, 还是做判断 - 哪些工作可以交给 AI, 哪些不能
### 本章核心能力 - 能判断该用哪种编程模式 - 能把目标说清楚, 并给出边界 - 能观察 Agent 的执行过程 - 能把重复成功的方法沉淀为 Skill
### 本章核心结论 - AI 辅助编程走向 Agent - Agent 适合边界清晰, 可验证的任务 - Skill 是把一次成功变成稳定能力的关键 - 人的价值转向 "定义目标, 约束过程, 审查结果"
