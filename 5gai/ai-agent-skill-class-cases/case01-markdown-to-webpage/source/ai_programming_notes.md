# 人工智能辅助编程：从聊天到 Agent

这部分课程接在“文本提示词”和“图像、视频生成”之后，目标不是让大家成为专业程序员，而是理解 AI 如何参与一个小型软件任务。

## 0. 为什么现在要学 AI 编程

很多同学可能会觉得：我不是计算机专业，为什么还要学编程？

原因不是每个人都要成为程序员，而是：

- 很多工作以后会变成“提出需求 + 检查结果”；
- AI 可以帮助我们把想法快速变成原型；
- 但如果完全不懂程序结构，就很难判断 AI 写出的东西能不能用；
- 信息管理专业至少应该理解数据、流程、界面和自动化。

> 本课程不要求大家记住复杂语法，但要求大家理解“一个程序是如何被拆成小步骤完成的”。

## 一、第一种方式：基于注释生成代码

在 Trae IDE 中，可以先写注释，再让 AI 根据注释补全代码。

例如：

```python
# 读取一个 CSV 文件
# 计算每个学生的平均分
# 输出最高分和最低分
```

AI 可能会根据这些注释生成相应的 Python 代码。

### 优点

- 上手快；
- 适合小函数；
- 适合补全重复代码；
- 对初学者比较友好。

### 局限

- 注释写得不清楚，生成结果会偏；
- 只适合局部任务；
- 对整体项目结构帮助有限；
- AI 不一定会主动检查结果。

## 二、第二种方式：基于聊天生成程序

可以在聊天窗口中直接提出需求：

> 请帮我写一个网页，可以添加待办事项、删除任务、标记完成。

AI 通常会给出完整代码。

### 优点

- 不需要先写代码；
- 可以快速生成一个可运行原型；
- 可以边问边改；
- 适合探索想法。

### 局限

- 很容易一次性生成太多代码；
- 代码结构可能不清楚；
- 学生容易只会复制粘贴；
- 如果出错，可能不知道如何调试。

## 三 Agent 模式

Agent 模式和普通聊天不同。

普通聊天更像是：

> 你问一句，它答一句。

Agent 更像是：

> 你给它一个任务，它会尝试规划、读取文件、修改文件、运行命令、观察结果，然后继续修复。

Agent 不只是“说”，还可以“做”。

例如：

1. 阅读项目目录；
2. 判断应该修改哪些文件；
3. 生成代码；
4. 运行测试；
5. 根据错误信息修改；
6. 最后给出总结。

## 四 Skill 是什么

Skill 可以理解为一套写给 AI Agent 的工作说明书。

如果说 prompt 是一次性的请求，那么 Skill 更像是可以反复使用的工作流程。

比如我们可以写一个：

- 网页生成 Skill；
- 数据清洗 Skill；
- 作业检查 Skill；
- 调试 Skill；
- 课程资料整理 Skill。

Skill 的作用是让 Agent 不只是“凭感觉做事”，而是按照我们定义的步骤做事。

## 六、三个概念的简要区别

### Chat

Chat 是对话。

适合：

- 问问题；
- 解释概念；
- 生成一小段代码；
- 修改一段文字。

### Agent

Agent 是可以执行任务的 AI 工作者。

适合：

- 多文件项目；
- 需要读写文件；
- 需要运行和修复；
- 需要分步骤完成的任务。

### Skill

Skill 是写给 Agent 的可复用说明书。

适合：

- 重复性任务；
- 有固定流程的任务；
- 对输出格式要求稳定的任务；
- 希望以后反复使用的任务。

## 七、容易出现的问题

学生使用 AI 编程时，常见问题包括：

1. 需求说得太模糊；
2. 只看运行结果，不看代码；
3. 代码出错后反复让 AI 猜；
4. 不知道如何验收；
5. 没有保存有效提示词；
6. 没有把成功经验沉淀成 Skill。

## 八、反思问题

请思考：

1. AI 写出来的代码，谁负责？
2. 如果 AI 给出的程序能运行，但你看不懂，这算完成了吗？
3. Agent 自动修改文件时，人应该在什么时候介入？
4. Skill 和普通提示词相比，真正多出来的是什么？
5. 未来工作中，哪些任务适合交给 Agent？

## 结语

AI 辅助编程不是让人退出编程，而是改变人在编程中的位置。

人更重要的工作变成：

- 提出问题；
- 设计目标；
- 描述约束；
- 检查结果；
- 总结流程；
- 把经验变成可复用 Skill。
