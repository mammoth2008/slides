# 术语表

## AI IDE

集成 AI 能力的编程环境。除了传统代码编辑功能外，还能提供代码生成、解释、重构、调试等能力。

## 注释生成代码

开发者先写自然语言注释，由 AI 根据注释生成对应代码。

## Chat

基于对话的 AI 使用方式。用户通过自然语言提出问题，AI 通过文本回答。

## Agent

可以围绕目标自主执行多步骤任务的 AI 系统。它通常能够调用工具、读取文件、修改文件、运行命令，并根据结果继续行动。

## Skill

写给 Agent 的可复用能力说明。通常包括任务适用范围、执行步骤、输出格式、检查标准等。

## 验收标准

判断一个任务是否完成的标准。对于 AI 编程来说，验收标准非常重要，因为 AI 生成的结果不等于结果一定正确。
