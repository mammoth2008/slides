# 网页生成要求

请把 `source/` 中的课程笔记转换成一个静态网页，用于《生成式人工智能与应用》课程中的“人工智能辅助编程”部分。

## 一、基本要求

生成的网页必须包括：

1. 页面标题；
2. 左侧或顶部目录导航；
3. 课程内容正文；
4. 关键概念卡片；
5. 课堂练习区；
6. “待补充内容”区；
7. 页脚，说明这是 AI 辅助生成的课程材料。

## 二、文件要求

必须生成以下文件：

```text
output/index.html
output/style.css
output/app.js
output/README.md
```

## 三、内容处理规则

1. 不得删除原始笔记中的重要内容。
2. 可以修正明显的标题层级混乱。
3. 可以把 TODO 项集中整理到“待补充内容”区。
4. 可以把术语解释整理成卡片。
5. 不要编造课程中没有出现的工具或理论。
6. 如果原文中有不确定内容，应在网页中标记为“需教师确认”。

## 四、视觉风格要求

1. 页面应适合课堂展示和学生自学。
2. 风格简洁、清楚，不要做成商业宣传页。
3. 字体大小要适合投影展示。
4. 内容区域宽度不要太窄。
5. 使用浅色背景。
6. 关键概念可以用卡片样式突出。
7. 不要依赖外部 CDN，不要联网加载字体或框架。

## 五、交互要求

`app.js` 至少实现一个简单交互功能，可从以下功能中任选：

1. 点击目录平滑滚动；
2. 点击按钮切换“显示/隐藏课堂练习”；
3. 生成阅读进度条；
4. 高亮当前阅读章节。

## 六、验收标准

完成后应检查：

1. `index.html` 可以直接用浏览器打开；
2. 标题层级合理；
3. 目录链接可以跳转；
4. 课堂练习没有丢失；
5. TODO 内容被集中整理；
6. 页面没有明显乱码；
7. 无需联网即可正常显示。
