# 验收标准

## 一、规划文档验收标准

如果只完成项目规划，必须包括：

1. 需求摘要；
2. 功能优先级；
3. 用户故事；
4. 页面结构；
5. 数据结构；
6. 任务拆解；
7. 验收测试；
8. 风险与待确认问题。

## 二、原型功能验收标准

如果实现网页原型，至少应满足：

1. 可以添加任务；
2. 任务包括：
   - 标题
   - 截止时间
   - 状态
   - 使用的 AI 工具
   - 反思内容
3. 可以删除任务；
4. 可以修改任务状态；
5. 刷新页面后任务仍然存在；
6. 可以按状态筛选任务；
7. 快到期任务有提示；
8. 页面能直接打开使用。

## 三、代码验收标准

1. 文件结构清楚；
2. 变量命名可读；
3. 主要函数有简单注释；
4. 不要把所有逻辑都堆在一个很长的函数里；
5. 不依赖网络；
6. 浏览器控制台没有明显报错。

## 四、反思验收标准

最终说明中需要回答：

1. 哪些需求被实现了？
2. 哪些需求没有实现？
3. 为什么这样取舍？
4. Agent 做了什么？
5. 人类需要检查什么？
