# 项目约束

## 技术约束

1. 只能使用 HTML、CSS、JavaScript。
2. 不使用后端。
3. 不使用数据库。
4. 不使用外部 CDN。
5. 不使用 React、Vue、Svelte 等框架。
6. 使用浏览器 localStorage 保存数据。
7. 页面应能直接用浏览器打开。

## 时间约束

课堂演示版本应能在 30 到 45 分钟内完成。

如果无法完成所有功能，优先完成：

1. 添加任务；
2. 显示任务；
3. 修改状态；
4. 删除任务；
5. 保存到 localStorage。

其次完成：

1. 筛选任务；
2. 任务反思；
3. 快到期提醒；
4. 导出 JSON。

## 设计约束

1. 页面简洁；
2. 字体大小适合课堂投影；
3. 不要使用过多动画；
4. 颜色不超过 4 种主色；
5. 移动端能基本使用；
6. 表单字段不要过多。

## 输出约束

如果只做项目规划，应输出到：

```text
output/requirements_summary.md
output/task_breakdown.md
output/file_structure.md
output/acceptance_test_plan.md
output/risk_and_questions.md
```

如果进一步实现原型，应输出到：

```text
project/index.html
project/style.css
project/app.js
project/README.md
```
