# 案例二：课程笔记/录音处理 Skill

## 课堂任务

让学生制作一个 Trae Skill，用于把课堂转写稿或零散笔记整理成复习材料。

本案例重点是训练学生区分三类内容：

- 老师明确讲过的内容。
- 根据上下文整理出来的结构。
- AI 推断但需要人工核对的内容。

## 建议目录

```text
course-note-demo/
  .trae/
    skills/
      course-note-processor/
        SKILL.md
  notes/
    raw_transcript.md
    teacher_slides_outline.md
  output/
```

## 原始材料 1：`notes/raw_transcript.md`

```markdown
# 课堂录音转写：数据库系统概论片段

今天我们讲数据库系统的几个基本组成。大家注意，不是只有数据库文件本身，数据库系统还包括数据库管理系统、应用程序、数据库管理员、用户以及运行环境。

数据库管理系统，简称 DBMS，它的作用可以理解为在用户和数据库之间提供统一的管理和访问接口。它负责数据定义、数据操纵、运行管理、安全控制和完整性控制。

这里有个地方容易混。数据库是数据集合，数据库管理系统是软件，数据库系统是更大的整体。考试和做系统分析的时候，这三个概念要分清。

后面我们会讲三类用户。第一类是数据库管理员，也就是 DBA，负责维护和管理数据库。第二类是应用程序员，他们通过程序访问数据库。第三类是终端用户，有些是偶然用户，有些是经常使用固定功能的简单用户，还有一些复杂用户会自己提出查询。

刚才有同学问，用 AI 生成 SQL 算不算学习数据库。我觉得要看学生做了什么。如果只是复制答案，那不是学习。如果能解释表结构、约束、查询逻辑，并且能发现 AI 写错的地方，这个过程就有学习价值。

今天课后任务是：选择一个小型业务场景，画出实体和关系，写出 3 条查询需求。下一次课我们用这些需求做 E-R 图和关系模式转换。

有一段我说得可能快了：数据库系统的运行环境包括硬件、软件、网络和人员组织条件。这个地方你们记成“软硬件”是不够的，还要看到管理制度和人员分工。
```

## 原始材料 2：`notes/teacher_slides_outline.md`

```markdown
# 本节 PPT 提纲

1. 数据库、数据库管理系统、数据库系统的区别
2. DBMS 的主要功能
   - 数据定义
   - 数据操纵
   - 数据库运行管理
   - 安全性控制
   - 完整性控制
3. 数据库系统中的人员角色
   - DBA
   - 系统分析员
   - 数据库设计人员
   - 应用程序员

4. AI 辅助 SQL 学习的边界
5. 课后任务：业务场景、实体关系、查询需求
```

## 完整 Skill 参考：`.trae/skills/course-note-processor/SKILL.md`

```markdown
---
name: course-note-processor
description: 当用户需要把课堂录音转写稿、课程笔记或 PPT 提纲整理成复习材料时使用。
---

# 目标

把原始课堂材料整理成适合学生复习的学习包，包括摘要、核心概念、知识结构、复习题和待核对点。重点是忠于原始材料，不把 AI 推断包装成老师原话。

# 适用场景

- 用户说“整理课堂笔记”“处理录音转写”“生成复习材料”。
- 项目中有 `notes/raw_transcript.md`、`notes/*.md` 或 PPT 提纲。
- 用户需要摘要、概念表、测验题或待复习清单。

# 输入约定

优先读取：

1. `notes/raw_transcript.md`
2. `notes/teacher_slides_outline.md`
3. 其他 `notes/` 下的补充材料

如果转写稿中出现明显错词、断句异常或缺上下文内容，必须列入待核对点。

# 工作流程

1. 通读原始材料，先判断本节主题和课程位置。
2. 提取老师明确讲过的概念、例子、提醒和课后任务。
3. 按“主题摘要、核心概念、结构图、复习题、待核对点”组织输出。
4. 对 AI 根据上下文补出的结构，标注为“整理性归纳”，不要写成老师原话。
5. 对听不清、疑似错词、缺少定义的内容，写入 `unclear-points.md`。
6. 生成适合学生复习的短问题，不生成过长论文式总结。
7. 最后按验收清单自查。

# 输出文件

必须输出：

- `output/class-summary.md`
- `output/concepts.md`
- `output/quiz.md`
- `output/unclear-points.md`

`class-summary.md` 包含：

- 本节主题
- 3-5 条核心要点
- 老师强调的易混点
- 课后任务

`concepts.md` 包含：

- 概念名称
- 简明解释
- 来源片段或依据
- 是否需要核对

`quiz.md` 包含：

- 5 道基础题
- 3 道理解题
- 2 道应用题
- 参考答案

# 禁止事项

- 不得补充老师没有讲过的案例，并伪装成课堂内容。
- 不得把“AI 推断”写成“老师指出”。
- 不得删除不确定内容，必须放入待核对点。
- 不得生成与课程无关的泛泛学习建议。
- 不得把课堂笔记改写成论文。

# 验收清单

完成后检查：

- 每个核心概念都能在转写稿或 PPT 提纲中找到依据。
- 听不清、缺上下文、疑似错词均已列入 `unclear-points.md`。
- 复习题覆盖概念区分、功能理解和应用任务。
- 输出适合学生复习，而不是教师会议纪要。
- 没有编造未出现的工具、理论或案例。
```

## 课堂提示词

```text
使用 course-note-processor 技能，读取 notes/ 下的课堂转写和 PPT 提纲，生成一套学生复习材料。注意区分老师明确讲过的内容、你的整理性归纳和需要人工核对的内容。
```
