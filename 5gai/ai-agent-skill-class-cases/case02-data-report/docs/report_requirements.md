# 报告要求

请基于课程作业数据生成一份 Markdown 报告。

报告文件路径：

```text
output/analysis_report.md
```

## 报告结构

报告必须包括以下部分：

1. 数据概况

   - 总记录数
   - 涉及学生数
   - 涉及作业类型
   - 涉及 AI 工具

2. 数据质量问题

   - 缺失值
   - 重复记录
   - 异常数值
   - 日期格式问题
   - 字段命名不统一

3. 作业完成情况

   - 各作业提交人数
   - 各作业平均质量评分
   - 视频作业是否满足 5 秒要求

4. AI 工具使用情况

   - 不同工具使用次数
   - 不同工具对应平均评分
   - 提示词修改次数与评分之间的关系

5. 结论与建议

   - 给学生的建议
   - 给教师的教学建议
   - 数据采集方式的改进建议

## 图表要求

如果可以，请生成以下图表：

```text
output/charts/tool_usage_count.png
output/charts/assignment_average_score.png
output/charts/prompt_count_vs_score.png
```

如果环境不支持生成图表，也应在报告中说明原因。

## 验收标准

1. 不覆盖原始 CSV；
2. 输出清洗后的 CSV；
3. 输出问题清单 CSV；
4. 输出 Markdown 报告；
5. 报告中的数字应来自实际数据计算；
6. 不要凭空编造结论；
7. 异常值要说明处理方式。
