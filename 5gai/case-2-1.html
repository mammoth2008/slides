### 案例一 研究报告任务 - 任务目标是生成一篇关于 生成式 AI 的研究报告 - 不同 Prompt 会导致内容质量差异 - 通过三种 Prompt 对比可以观察 LLM 的行为变化
### 最模糊的 Prompt - 写一篇关于人工智能的研究报告 - 不指定主题范围 - 不指定读者对象 - 不指定字数或结构 - 输出通常泛泛而谈内容重复
### 一般水平的 Prompt - 写一篇 2000 字 的研究报告 - 主题是生成式人工智能 - 介绍技术原理、应用场景、和未来趋势 - 面向大学生读者 - 输出质量明显提升 - 但仍可能缺少结构深度
### 最佳实践级别的 Prompt - 你是一名信息技术研究者 - 写一篇 2000 字 的研究报告 - 主题为《生成式人工智能的技术原理与应用》 - 读者为信息管理专业本科生 - 使用结构: 引言、技术原理、应用案例、风险与挑战、总结 - 引用可信的真实研究或技术趋势
### 案例二 学习一门课程 - 任务目标是制定学习计划 - Prompt 的细化会显著提升实用性
### 最模糊的 Prompt - 我想学习机器学习 - 推荐学习资料 - 输出通常是一般性的教材列表
### 一般水平的 Prompt - 我是一名本科生 - 想学习机器学习基础 - 请推荐学习路线和参考书 - 输出通常包括基础课程和推荐书籍
### 最佳实践级别的 Prompt - 我是一名信息管理专业本科三年级学生 - 编程能力一般 - 了解基础统计学 - 希望在 3 个月内理解机器学习基本概念 - 请设计一个每周学习计划 - 包括推荐教材、在线课程和实践任务
### 案例三 翻译与理解 - 任务目标是翻译并理解一段专业文本 - Prompt 的改进会影响解释深度
### 最模糊的 Prompt - 翻译下面的文本 - 输出通常是简单逐句翻译
### 一般水平的 Prompt - 将下面的英文文本翻译成中文 - 保持学术风格 - 输出通常是较为准确的翻译
### 最佳实践级别的 Prompt - 将下面的英文文本翻译为中文 - 保持学术表达的准确性 - 同时解释关键术语 - 用简单语言说明该段落的核心观点 - 最后总结该研究的意义
### 案例四 信息整理任务 - 任务目标是总结一段长文本
### 最模糊的 Prompt - 总结这段文字 - 输出通常过于简短
### 一般水平的 Prompt - 总结这段文章的主要内容 - 用 3 到 5 个要点
### 最佳实践级别的 Prompt - 阅读下面的文章 - 用 5 个要点总结核心观点 - 每个要点不超过 30 字 - 最后给出一句总体结论
### 推荐书籍 - 学会提问 - 批判性思维工具 - 思考, 快与慢 - 好好思考 - 金字塔原理 - 如何阅读一本书
### 学会提问 - 作者 Neil Browne 与 Stuart Keeley - 介绍批判性思维的基本方法 - 强调质疑、论证和推理
### 批判性思维工具 - 作者 Richard Paul 与 Linda Elder - 系统介绍批判性思维框架 - 常用于大学思维训练课程
### 思考, 快与慢 - 作者 Daniel Kahneman - 解释人类思维的两种模式 - 揭示常见认知偏差
### 好好思考 - 作者 成甲 - 介绍结构化思考方法 - 强调问题分析和信息整理
### 金字塔原理 - 作者 Barbara Minto - 介绍结构化表达和逻辑组织 - 常用于商业写作和报告分析
### 如何阅读一本书 - 作者 Mortimer Adler 与 Charles Van Doren - 强调深度阅读与分析能力 - 帮助读者理解复杂思想
