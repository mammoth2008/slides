### 意图表达与控制 - 不同模态本质上是对不同维度的控制 - 图片控制视觉结构 - 视频控制时间结构 - 音乐控制听觉结构 - 重要的是控制能力 - AI 生成过程是人机协作的循环
### 多模态统一控制维度 - 图片: 主体、场景、风格、构图、光线、细节 - 视频: 主体、动作、镜头、时序、转场、节奏、一致性 - 音乐: 风格、配器、情绪、节奏、结构、歌词 - 提示词是对这些维度的描述 - 控制越清晰, 输出越稳定
### 图片生成 - 控制一张图的内容和风格 - 从描述走向可控生成 - 从单句提示词走向工作流
### 案例一 - 一个女孩的肖像, 电影级光照, 35毫米胶片风格, 柔和光线 - 主体 + 光线 + 风格
### 案例二 - 未来城市, 霓虹灯, 赛博朋克风格, 夜晚, 超高细节 - 场景 + 风格 + 时间
### 案例三 - 中国水墨画风格, 山水景观, 薄雾, 极简主义 - 风格 + 构图 + 文化元素
### 产品地图 - Midjourney 以风格表现力强著称 - DALL·E 与 ChatGPT 结合 - Nano Banana 与 Gemini 结合 - Stable Diffusion 开源生态强 - Ideogram 擅长文字生成与排版 - FLUX 新一代高质量模型 - 国内产品: 豆包、即梦、可灵等
### 工作流工具 - WebUI 提供参数化控制 - ComfyUI 提供节点式工作流 - Fooocus 自动优化提示词 - 工作流代表从提示词走向流程控制 - 用户从写一句话变成构建生成流程
### 原理概述 - 基于 Diffusion Model - 从随机噪声逐步去噪生成图像 - latent diffusion 降低计算成本 - 文本通过编码器转为条件 - 模型根据条件生成图像
### 演化 - 阶段1: 描述式提示词 - 主体 + 风格 + 场景 - 阶段2: 技巧化提示词 - 风格词堆叠、参数词 - 阶段3: 工作流 + 提示词 - Reference Image 控制结构 - 阶段4: 上下文工程 - LLM 自动扩展提示词
### 示例对比 - 一个女孩 - 一个女孩, 动漫风格 - 一个女孩, 动漫风格, 吉卜力工作室风格, 低饱和度 - 控制维度逐步增加
### 课堂练习 - 修改同一个提示词 - 增加风格词 - 比较不同光线效果 - 尝试改变构图方式 - 分析输出差异 - 总结控制维度
### 常见问题 - 人物结构错误 - 手部细节不准确 - 风格不稳定 - 文字生成错误 - 结果不可控
### 视频生成 - 如何控制画面随时间变化 - 如何描述镜头与动作 - 如何实现多镜头叙事
### 案例一 - 一位女性在城市中行走, 跟拍镜头, 电影级光照 - 动作连贯, 镜头平滑 - 主体 + 动作 + 镜头
### 案例二 - 一只猫跳跃, 慢动作, 特写镜头, 戏剧性光照 - 动作清晰, 节奏控制明显 - 动作 + 时间 + 镜头
### 案例三 - 无人机拍摄山脉, 日出, 薄雾, 广角镜头 - 场景宏大, 画面稳定 - 场景 + 镜头 + 时间
### 产品地图 - Sora 支持高质量长视频生成 - Runway 提供视频编辑与生成 - Pika 支持快速生成短视频 - Luma 强调 3D 一致性 - 国内: 即梦、可灵、海螺等
### 原理概述 - 基于图像 Diffusion 扩展 - 增加时间维度建模 - 使用时序一致性约束 - 多阶段生成提升质量 - 核心难点是稳定性
### 视频提示词结构 - 主体 + 动作 + 镜头 + 场景 + 时间 - 镜头语言非常重要 - 动作描述影响动态效果 - 时间控制影响节奏 - 需要更强结构表达
### 视频提示词演化 - 描述画面 - 描述动作 - 描述镜头 - 多镜头叙事 - LLM 生成分镜
### 课堂练习 - 增加镜头描述 - 改变动作类型 - 加入时间控制 - 比较不同效果 - 总结关键维度
### 常见问题 - 人物不一致 - 动作不自然 - 镜头跳跃 - 物理不合理 - 长视频稳定性差
### 音乐生成 - 如何控制音乐风格和情绪 - 如何描述节奏和结构 - 如何结合歌词与旋律
### 案例一 - 悲伤的钢琴音乐, 慢节奏 - 情绪明确, 节奏缓慢 - 情绪 + 节奏
### 案例二 - 爵士音乐, 萨克斯, 欢快节奏 - 风格明显, 节奏活跃 - 风格 + 配器 + 节奏
### 案例三 - 电影配乐, 管弦乐, 史诗风格, 合唱 - 情绪强烈, 结构丰富 - 风格 + 结构 + 情绪
### 产品地图 - Suno 文本生成完整歌曲 - Udio 高质量音乐生成 - MusicGen 开源模型 - MusicLM Google研究项目 - 国内: MiniMax、seed-Music、网易
### 原理概述 - 基于 Audio Token 或 Latent 表示 - 使用 Transformer 或 Diffusion - 文本转为音乐条件 - 生成长时序音频 - 强调结构与一致性
### 提示词结构 - 风格 + 情绪 + 节奏 + 配器 + 结构 - 可以加入歌词 - 可以描述段落 - 可以指定节拍 - 可以参考风格
### 音乐提示词演化 - 简单风格词 - 风格 + 情绪 - 结构化描述 - 长时序控制 - LLM 生成歌词与结构
### 音乐提示词示例对比 - 悲伤的音乐 - 悲伤的钢琴音乐, 慢节奏 - 慢节奏, 小调钢琴配柔和弦乐, 富有情感的电影配乐 - 情绪与结构逐步清晰
### 课堂练习 - 改变音乐风格 - 控制节奏快慢 - 增加配器描述 - 尝试生成歌词 - 比较输出差异
### 常见问题 - 结构混乱 - 情绪不稳定 - 风格混杂 - 人声不自然 - 长度控制困难
### 本章总结 - 多媒体生成本质是控制问题 - 提示词是意图表达的入口 - 控制维度决定输出质量 - LLM 正在重塑提示词工程 - 未来是上下文与工作流驱动生成
