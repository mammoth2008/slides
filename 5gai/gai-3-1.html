### 从自动补全到自主执行 - 2022: ChatGPT 发布, AI 进入公众视野 - 2022: GitHub Copilot 正式发布, 代码补全时代开启 - 2023: Cursor 等对话式 IDE 集中涌现 - 2024: Devin, Claude Code, Agent 自主执行进入视野 - 2025: Trae 整合对话, 上下文, Agent, 工具链
### 代码补全时代 - GitHub Copilot (2021) 是标志性起点 - 模式: 写注释或函数名, AI 续写代码 - 局限: 只能在已知上下文中续写 - 突破: 大幅提升局部代码的编写效率 - 代表工具: GitHub Copilot, Tabnine
![GitHub Copilot 界面](img/c03/github-copilot.png) #### GitHub Copilot: 代码补全
### 对话式编程时代 - Cursor 将对话式交互作为 IDE 核心 (2023) - 模式: 用自然语言描述需求, AI 生成或修改代码 - 突破: 可以跨文件理解上下文 - 代表工具: Cursor, Trae, Amazon CodeWhisperer
![Cursor IDE 界面](img/c03/cursor.webp) #### Cursor: 对话式 IDE
### Agent 自主执行时代 - Claude Code (2024) 引入自主执行链路 - 模式: AI 理解目标, 拆解任务, 逐步执行 - 突破: 从 "回答问题" 变为 "完成任务" - 代表工具: Claude Code, Devin, Trae Agent 模式
### 主流范式的更迭 - 范式一: 补全 - AI 在人类写好的上下文中续写 - 范式二: 对话 - 人类描述需求, AI 生成或修改 - 范式三: 自主 - AI 理解目标, 自主规划与执行 - 当前: 三种范式并存, Trae 同时支持全部三种
### 重要工具地图 - GitHub Copilot: 补全时代开创者, 与 VS Code 深度集成 - Tabnine: 老牌补全工具, 支持本地部署 - Cursor: 对话式 IDE 先驱, 引入 Cmd+K 范式 - Trae: 字节跳动, 对话 + 智能体 + MCP, 全链路整合 - Claude Code: Anthropic, Agent 模式代表, 极简界面 - Devin: Cognition Labs, 首个商业 AI 软件工程师
### 字节跳动 Trae - 整合多个国内大模型: Doubao-Seed, DeepSeek, Kimi, Qwen - 支持对话式编程, 代码补全, 项目级生成 - 内置 Agent 模式和 MCP 协议扩展 - 本章主工具: Trae
![Trae 界面](img/c03/trae.png) #### Trae: 全链路整合
### Anthropic Claude Code - 极简 CLI 界面, 专注 Agent 执行 - 强调批判性思维和结果评估 - 适合理解 Agent 执行链路的工作原理 - 本章对比参考工具
![Claude Code 界面](img/c03/Claude-code.png) #### Claude Code: Agent 执行
