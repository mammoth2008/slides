### Prompt (提示词) - 告别玄学 - 结构化 - 编程化 - 可优化
### Context (上下文) - 百万级长上下文 - 解决大海捞针问题 - 能够一次性读完整个代码库
### LLM (大语言模型) - 引入思维链（CoT） - 学会了自我反思 - 学会了纠错 - 攻克了数学和编程难题
### Memory (记忆) - 实现了跨会话的长期记忆 - 记住用户的偏好、职业背景 - 记住决策逻辑
### RAG (检索增强生成) - 能联网检索 - 理解知识图谱中的复杂关系 - 解决了 LLM 处理企业私有数据的落地难题
### Skill (函数调用与技能) - 技能被抽象为原子化的 API - LLM 能够根据需求自动选择并组合工具 - 支付、订票、数据抓取等任务实现了全自动触发
### MCP (模型上下文协议) - Anthropic 推出 - 统一了模型与数据源、工具之间的连接标准 - 一次编写, 多次调用
### Agent (智能体) - 具备了自主规划（Planning）和执行能力 - 能主动观察环境、设定目标并解决问题 - 形成了真正的“闭环生产力”。
### SubAgent (子智能体) - 开启了多智能体系统 - 主智能体负责拆解任务 - 分发给专门负责搜索、代码、审计的子智能体 - 提升了处理复杂工程的能力
### Workflow (工作流) - 确定性逻辑与生成式逻辑融合 - 复杂的业务流程被拆解为标准工作流 - 模型负责在关键节点进行分类和判断
### Frameworks (框架演进) - 更注重可观测性 - 注重编排灵活性
### Token Economics (Token 经济学) - 缓存技术和推理优化 - Token 成本下降了 90% 以上 - 高性能小模型崛起 - 边缘 AI 正在更具性价比
